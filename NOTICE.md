# Project Notice

This repository is an AI-assisted experimental offline-signer project.

It is intended for learning, discussion, and test-only validation.
It is not a finished production wallet stack and must not be treated as
audited mainnet-custody software.

Do not store real seed phrases, private keys, or real money on builds
derived from this repository.

## Current Maintainer

- `akg5188`

## Main Repository Roots

- `seedsigner-os/`: Raspberry Pi offline signer operating system and image tooling
- `app/`: Android smart-card companion app
- `wallet/`: Android high-security watch-only wallet
- `pi-signer/`: JVM CLI signer for Pi OS workflows
- `backups/satochip-utils/`: offline backup of Satochip-Utils
