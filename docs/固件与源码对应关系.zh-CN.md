# 固件与源码对应关系

这页只回答一个问题：当前正式固件到底对应哪份源码。

## 1. 当前正式固件

定位：

- 当前 GitHub Releases 公开发布的正式树莓派固件
- 也是仓库 `dist/` 里当前正式保留的镜像

关键值：

- 镜像：
  `dist/system-update-latest.img.xz`
- `sha256`：
  `0a522a4329d476b9bb431b7197d6af07d3dd88feb1fa0e93ed97bf0fb66c6055`
- `repo_head`：
  `281d45bfddb9b9150f48c840fafb3aa63aa624fb`
- `repo_dirty=0`
- `build_clean_mode=clean`
- 固件 release tag：
  `offline-signer-firmware-20260410b-clean`
- 源码冻结 tag：
  `offline-signer-clean-source-20260410b`

这张就是当前正式推荐使用的固件，不再区分“GitHub 当前推荐测试包”和“本机正式 clean 包”两套口径。

## 2. 这次正式固件对应的源码范围

源码冻结提交：

- `281d45bfddb9b9150f48c840fafb3aa63aa624fb`

这份冻结里包含：

- 小屏 UI 排版收口，长内容优先改成摇杆上下滚动
- 签名完成后先显示摘要，再决定是否显示二维码
- 写卡后自动回读核验，覆盖指纹、`xpub / zpub`、首个地址和测试签名
- `查看助记词` 底部滚动留白修复
- `拍照创建助记词` 原始熵显示修复
- 固件 smoke、桌面模拟、真实 UI 截图和模块导入检查

## 4. 当前 `main` 是什么

`main` 是滚动开发线，不要把它当成任意历史镜像的精确来源。

想追溯当前正式固件，只看：

- `offline-signer-clean-source-20260410b`

想看仓库当前滚动开发状态，才看：

- `main`

```bash

```
