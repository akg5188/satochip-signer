## 3. 当前 `main` 是什么

`main` 是滚动开发线，不要把它当成任意历史镜像的精确来源。

想看当前 `main`，直接运行：

```bash
git rev-parse main
```

它包含：

- 修正后的文档
- `review-pinless` 的映射说明
- 让 clean 构建不再回写源码树的可复现性修复

但它不等于任意一张已发布固件的精确源码冻结点。

## 4. 下次该怎么切源码

### 想追溯当前 clean 正式包

```bash
git checkout offline-signer-clean-source-20260401
```

### 想追溯历史 `review-pinless` 功能包

```bash
git checkout offline-signer-review-pinless-source-20260401
```

### 想看仓库当前最新文档与源码

```bash
git checkout main
```

## 5. 最重要的原则

- `system-update-latest` 看当前 clean 正式 tag
- 历史功能包看各自冻结 tag
- 不要拿当前 `main` 直接代替任意一张历史镜像
- 发布入口和历史版本怎么区分，再看：
  [版本时间线与发布入口](版本时间线与发布入口.zh-CN.md)
