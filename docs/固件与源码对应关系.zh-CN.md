# 固件与源码对应关系

这页只回答一个问题：当前正式固件到底对应哪份源码。

## 1. 当前正式固件

定位：

- 当前 GitHub Releases 公开发布的正式树莓派固件
- 也是仓库 `dist/` 里当前正式保留的镜像

关键值：

- 镜像：
  `dist/system-update-latest.img.xz`
- `sha256`：
  `98ce03bc4e0920e0ac555c851384d623fba9c09da9c19df531c575ac5a450023`
- `repo_head`：
  `8a87ae5d1d19d3a7a2809a2b13327afee490364f`
- `repo_dirty=0`
- `build_clean_mode=clean`
- 固件 release tag：
  `offline-signer-firmware-20260408-clean`
- 源码冻结 tag：
  `offline-signer-clean-source-20260408`

这张就是当前正式推荐使用的固件，不再区分“GitHub 当前推荐测试包”和“本机正式 clean 包”两套口径。

## 2. 这次正式固件对应的源码范围

源码冻结提交：

- `8a87ae5d1d19d3a7a2809a2b13327afee490364f`

这份冻结里包含：

- `BlueWallet` 扫回已签名 `BTC PSBT` 的二维码兼容性修复
- 已签名 `PSBT` 按输入格式回传
- `PSBT / 已签名交易` 自动动画二维码恢复
- 二维码显示尺寸修正
- 固件 smoke、桌面模拟、二维码 round-trip、模块导入 smoke

## 4. 当前 `main` 是什么

`main` 是滚动开发线，不要把它当成任意历史镜像的精确来源。

想追溯当前正式固件，只看：

- `offline-signer-clean-source-20260408`

想看仓库当前滚动开发状态，才看：

- `main`
