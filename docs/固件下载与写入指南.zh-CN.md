# 固件下载与写入指南

这份文档是给以后忘了“固件去哪里拿、怎么写进去”时直接照着做用的。

本项目里你主要会碰到两种固件：

- `J3R180` 智能卡固件
- 树莓派签名器固件

它们不是一回事，写入方法也完全不同。

## 1. J3R180 智能卡固件

### 1.1 固件文件在哪里

本仓库里的预编译 CAP 文件就在这里：

- 仓库路径：`card-applet/prebuilt/SatoChip-3.0.4.cap`
- Release 页面：
  `https://github.com/akg5188/tp-satochip-signer/releases/tag/j3r180-card-firmware-20260318`
- Release 直接下载：
  `https://github.com/akg5188/tp-satochip-signer/releases/download/j3r180-card-firmware-20260318/SatoChip-3.0.4.cap`
- Release 校验文件：
  `https://github.com/akg5188/tp-satochip-signer/releases/download/j3r180-card-firmware-20260318/SHA256SUMS.txt`
- GitHub 页面：
  `https://github.com/akg5188/tp-satochip-signer/blob/main/card-applet/prebuilt/SatoChip-3.0.4.cap`
- 直接下载：
  `https://raw.githubusercontent.com/akg5188/tp-satochip-signer/main/card-applet/prebuilt/SatoChip-3.0.4.cap`
- 校验文件：
  `https://github.com/akg5188/tp-satochip-signer/blob/main/card-applet/prebuilt/SHA256SUMS.txt`

当前校验值：

```text
ded5a2efbb8a417109a629dd0e0e09711e1ea2c90da4bab79e719cef9f933ec7  SatoChip-3.0.4.cap
```

### 1.2 什么时候用这个文件

如果你手里是：

- `J3R180` 白卡
- 还没有写入 Satochip applet

那就用这个 CAP 文件。

### 1.3 写入前准备

你至少需要：

- Linux 电脑
- `ACS ACR39U` 或兼容读卡器
- `J3R180` 卡
- `openjdk-11-jdk`
- `pcsc-tools`
- `opensc`
- `GlobalPlatformPro`

安装常用工具：

```bash
sudo apt install -y openjdk-11-jdk pcsc-tools opensc wget
```

下载 `gp.jar`：

```bash
mkdir -p ~/card-work && cd ~/card-work
wget -O gp.jar https://github.com/martinpaljak/GlobalPlatformPro/releases/latest/download/gp.jar
```

### 1.4 检查读卡器和卡

```bash
pcsc_scan
```

看到 `Card inserted` 说明读卡器和卡都正常。

### 1.5 写卡命令

假设你的 CAP 文件已经下载到当前目录，或者直接用仓库里的文件：

```bash
CAP=/path/to/SatoChip-3.0.4.cap
java -jar gp.jar -install "$CAP"
java -jar gp.jar -l
```

如果 `-l` 里看到下面这些内容，就说明装进去了：

- `APP: 5361746F4368697000 (SELECTABLE)`
- `PKG: 5361746F43686970 (LOADED)`

### 1.6 再做一次 SELECT 验证

```bash
opensc-tool -s 00A40400085361746F43686970
```

如果返回：

```text
SW1=0x90, SW2=0x00
```

就表示 applet 可选中，卡固件写入成功。

### 1.7 写完卡以后下一步做什么

写完固件不代表全部完成。

后面你通常还要做：

- 在 `Tails OS` 里用 `Satochip-Utils` 设置 `PIN`
- 导入或生成助记词

对应教程看：

- [../backups/satochip-utils/Tails-离线使用教程.zh-CN.md](../backups/satochip-utils/Tails-离线使用教程.zh-CN.md)

### 1.8 更完整卡固件教程

如果以后你还想自己编译 CAP，而不是直接用预编译文件，看这里：

- [../card-applet/CAP_BUILD_AND_INSTALL.zh-CN.md](../card-applet/CAP_BUILD_AND_INSTALL.zh-CN.md)

## 2. 树莓派签名器固件

### 2.1 固件文件在哪里

当前仓库里的树莓派镜像文件在这里：

- 仓库路径：`dist/system-update-latest.img.xz`
- 构建记录：`dist/system-update-latest.build-info.txt`
- GitHub Releases 页面：
  `https://github.com/akg5188/tp-satochip-signer/releases`
- GitHub 页面：
  `https://github.com/akg5188/tp-satochip-signer/blob/main/dist/system-update-latest.img.xz`
- 直接下载：
  `https://raw.githubusercontent.com/akg5188/tp-satochip-signer/main/dist/system-update-latest.img.xz`
- 校验文件：
  `https://raw.githubusercontent.com/akg5188/tp-satochip-signer/main/dist/system-update-latest.img.xz.sha256`

当前校验值：

- 以仓库里的 `dist/system-update-latest.img.xz.sha256` 为准
- 这次 GitHub 备份对应的当前值是：

```text
50d633dc207f6a0c80adeb2b551851cb0610df5c16f21bfde67075303a077982  system-update-latest.img.xz
```

### 2.2 什么时候用这个镜像

如果你要：

- 给树莓派重新刷系统
- 新做一张 TF 卡
- 机器系统坏了要恢复

那就用这个镜像。

如果你还需要外壳文件包，也在同一个 release 里：

- `seedsigner-case-files-20260308.tar.gz`
- 仓库路径：
  `dist/seedsigner-case-files-20260308.tar.gz`

### 2.3 烧录前准备

你需要：

- 一张 TF 卡
- 一台 Linux、macOS 或 Windows 电脑
- 树莓派设备

### 2.4 先校验镜像

```bash
cd /path/to/tp-satochip-signer/dist
sha256sum -c system-update-latest.img.xz.sha256
```

看到 `OK` 再继续。

### 2.5 Linux 下烧录 TF 卡

先确认 TF 卡设备名：

```bash
lsblk
```

然后烧录：

```bash
xzcat system-update-latest.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

把 `/dev/sdX` 换成你的 TF 卡设备。

### 2.6 图形工具烧录

如果你不想用命令行，也可以用常见的镜像烧录工具：

- Raspberry Pi Imager
- balenaEtcher

思路都是一样：

1. 选择 `system-update-latest.img.xz`
2. 选择 TF 卡
3. 点击写入

### 2.7 首次启动后看什么

烧录完成后：

1. 把 TF 卡插到树莓派
2. 开机
3. 看设备能否正常进入签名器界面
4. 用手机中转二维码试一笔签名流程

### 2.8 如果以后镜像文件不见了怎么办

## 3. 最简单记忆法

以后你只要记住：

- 卡固件看 `card-applet/prebuilt/SatoChip-3.0.4.cap`
- 树莓派固件看 `dist/system-update-latest.img.xz`
- 卡初始化工具看 `backups/satochip-utils`

就不会乱。
