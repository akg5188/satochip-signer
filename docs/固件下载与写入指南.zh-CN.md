## 1. 树莓派离线签名器固件

### 当前推荐树莓派固件

- 如果你现在就在这台电脑上直接刷：
  - `dist/system-update-steel-restore-fix-test.img.xz`
  - `dist/system-update-steel-restore-fix-test.img.xz.sha256`
- 如果你是从 GitHub Releases 公开下载：
  - `offline-signer-firmware-20260405-seedkeeper-suite-current`
  - `system-update-seedkeeper-suite-test.img.xz`

当前校验值：

```text
b72be80ddd80484710092a46723a30c59b9e5298796d7fdc81b8b369cb080141  system-update-seedkeeper-suite-test.img.xz
```

这张现在已经同步成 GitHub 当前公开下载固件。
本机 `dist/` 里的文件名和 GitHub 公开文件名不同，但内容相同。

它怎么对应源码，看：

- [固件与源码对应关系](固件与源码对应关系.zh-CN.md)
- [当前测试固件功能与验证范围](当前测试固件功能与验证范围.zh-CN.md)

### 当前 clean 基线

另外还保留：

- `dist/system-update-latest.img.xz`

这张主要是以后做严格重建、对 `sha256` 的 clean 基线，不是现在首先推荐你刷来体验最新功能的包。

### Linux 下校验

以当前推荐包为例：

```bash
cd dist
sha256sum -c system-update-steel-restore-fix-test.img.xz.sha256
```

如果你是从 GitHub Releases 下载，不要只校验文件，还要一起核对：

- release 名称是不是 `offline-signer-firmware-20260405-seedkeeper-suite-current`
- 资产文件名是不是 `system-update-seedkeeper-suite-test.img.xz`
- `sha256` 是不是：
  `b72be80ddd80484710092a46723a30c59b9e5298796d7fdc81b8b369cb080141`

### Linux 下烧录 TF 卡

```bash
lsblk
xzcat system-update-steel-restore-fix-test.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

把 `/dev/sdX` 换成你的 TF 卡。

### 首次启动后先做什么

1. 进入首页 `离线签名器`
2. 先跑一次 `固件完整性自检`
3. 再试一笔真实扫码流程

注意：

- 自检能发现关键文件缺失、被改、被额外塞文件
- 但如果有人整张卡重刷，仍然要对照 GitHub 上的 `build-info`、`sha256` 和源码 tag
