## 1. 当前正式树莓派固件

### 当前正式树莓派固件入口

- 如果你现在就在这台电脑上直接刷：
  - `dist/system-update-latest.img.xz`
  - `dist/system-update-latest.img.xz.sha256`
- 如果你是从 GitHub Releases 公开下载：
  - `offline-signer-firmware-20260410b-clean`
  - `system-update-latest.img.xz`

当前校验值：

```text
0a522a4329d476b9bb431b7197d6af07d3dd88feb1fa0e93ed97bf0fb66c6055  system-update-latest.img.xz
```

对应正式源码冻结：

- `offline-signer-clean-source-20260410b`
- `repo_head = 281d45bfddb9b9150f48c840fafb3aa63aa624fb`

这张就是当前正式固件：

- 仓库 `dist/` 里保留的是这张
- GitHub 公开下载入口指向的也是这张
- 公开下载 tag 统一看 [版本时间线与发布入口](版本时间线与发布入口.zh-CN.md)

它怎么对应源码，看：

- [固件与源码对应关系](固件与源码对应关系.zh-CN.md)
- [版本时间线与发布入口](版本时间线与发布入口.zh-CN.md)
- [当前测试固件功能与验证范围](当前测试固件功能与验证范围.zh-CN.md)

### 这次正式固件的重点

- 小屏 UI 重新排版，长内容优先改成摇杆上下滚动
- 签名完成后先显示人能看懂的摘要，再决定是否显示二维码
- 写卡后自动回读核验，覆盖指纹、`xpub / zpub`、首个地址和测试签名
- 修复 `查看助记词` 底部滚动留白问题
- 修复 `拍照创建助记词` 后查看原始熵不显示的问题

### Linux 下校验

```bash
cd dist
sha256sum -c system-update-latest.img.xz.sha256
```

如果你是从 GitHub Releases 下载，不要只校验文件，还要一起核对：

- release 名称是不是 `offline-signer-firmware-20260410b-clean`
- 资产文件名是不是 `system-update-latest.img.xz`
- `sha256` 是不是：
  `0a522a4329d476b9bb431b7197d6af07d3dd88feb1fa0e93ed97bf0fb66c6055`

### Linux 下烧录 TF 卡

```bash
lsblk
xzcat system-update-latest.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

把 `/dev/sdX` 换成你的 TF 卡。

### 首次启动后先做什么

1. 进入首页 `离线签名器`
2. 先跑一次 `固件自检`
3. 再试一笔真实扫码流程

注意：

- 自检能发现关键文件缺失、被改、被额外塞文件
- 但如果有人整张卡重刷，仍然要对照 GitHub 上的 `build-info`、`sha256` 和源码 tag
