# 仓库结构说明

这份文档按当前源码重新整理，只回答一件事：每个目录现在到底干什么。

## 核心目录

| 目录 | 当前用途 | 关键入口 |
| --- | --- | --- |
| `seedsigner-os/` | 树莓派离线签名器源码与 Buildroot 集成 | `opt/rootfs-overlay/opt/src/seedsigner/views/tp_views.py` |
| `app/` | `TokenPocket` 配套安卓智能卡签名/中转 App | `app/src/main/java/com/tpsigner/` |
| `wallet/` | 安卓高安全观察钱包 | `wallet/app/src/main/java/io/arbitrum/wallet/` |
| `card-applet/` | `J3R180` 智能卡固件 | `card-applet/prebuilt/SatoChip-3.0.4.cap` |
| `backups/satochip-utils/` | `Tails` 离线卡初始化工具备份 | 对应中文教程 |
| `dist/` | 当前仓库保留的固件、APK、校验文件 | 树莓派镜像和钱包 APK 都在这里 |
| `scripts/` | 统一构建、打包、验包脚本 | 根目录标准入口 |

## `seedsigner-os/`

当前最关键的代码集中在：

- `seedsigner-os/opt/rootfs-overlay/opt/src/seedsigner/views/tp_views.py`
- `seedsigner-os/opt/rootfs-overlay/opt/src/seedsigner/models/seed.py`
- `seedsigner-os/opt/rootfs-overlay/opt/src/seedsigner/helpers/firmware_integrity.py`

它现在不是旧文档里的“TP only mode”。

当前主页标题就是：

- `离线签名器`

首页 4 个入口：

- `扫码签名`
- `助记词工具`
- `固件完整性自检`
- `智能卡工具`

## `app/`

当前安卓 App 名字是：

- `智能卡`

对应源码里的定位：

- `TP` 请求二维码解析
- `NFC / USB-OTG` 智能卡签名
- 结果二维码回扫
- 可选的树莓派静态中转二维码

关键文件：

- `app/src/main/java/com/tpsigner/MainActivity.kt`
- `app/src/main/java/com/tpsigner/MainViewModel.kt`
- `app/src/main/java/com/tpsigner/SatochipSigner.kt`
- `app/src/main/java/com/tpsigner/TpQrCodec.kt`
- `app/src/main/java/com/tpsigner/RelayQrCodec.kt`
- `app/src/main/java/com/tpsigner/NfcCardManager.kt`
- `app/src/main/java/com/tpsigner/UsbCcidCardManager.kt`

## `wallet/`

当前不是旧方案里的内置网页钱包。

源码显示它现在是：

- `Arbitrum One` 高安全观察钱包
- `WalletConnect v2` 协调器
- 树莓派签名请求生成器
- 树莓派回签结果回传与人工确认广播器
- `BTC` 观察账户原型

关键文件：

- `wallet/app/src/main/java/io/arbitrum/wallet/MainActivity.kt`
- `wallet/app/src/main/java/io/arbitrum/wallet/MainViewModel.kt`
- `wallet/app/src/main/java/io/arbitrum/wallet/BiometricGateActivity.kt`
- `wallet/app/src/main/java/io/arbitrum/wallet/WalletConnectBridge.kt`
- `wallet/app/src/main/java/io/arbitrum/wallet/BitcoinTransferService.kt`
- `wallet/app/src/main/java/io/arbitrum/wallet/TrustedNetwork.kt`

## `dist/`

当前仓库里最重要的几个产物：

- `system-update-offline-signer-repair7.img.xz`
- `system-update-offline-signer-repair7.img.xz.sha256`
- `system-update-offline-signer-repair7.build-info.txt`
- `system-update-latest.img.xz`
- `system-update-latest.img.xz.sha256`
- `system-update-latest.build-info.txt`
- `satochip-wallet-release.apk`
- `satochip-wallet-release.apk.sha256`
- `satochip-wallet-release.build-info.txt`

注意：

- `tp-qr-relay-android-latest.apk` 默认按需构建，不一定长期保留在仓库 `dist/`
- `system-update-latest` 和 `repair7` 不是同一个版本

## `scripts/`

以后优先用这些脚本，不要直接裸跑子模块内部命令：

- `scripts/build_pi_firmware_from_snapshot.sh`
- `scripts/check_release_artifacts.sh`
- `scripts/run_seedsigner_build.sh`
- `scripts/build_tp_relay_apk.sh`
- `scripts/build_wallet_release.sh`
