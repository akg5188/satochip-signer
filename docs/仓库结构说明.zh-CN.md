# 仓库结构说明

这份文档是给以后看仓库结构时快速分辨用途用的。

## 五个核心部分

### 1. `card-applet`

这是：

- `J3R180` 智能卡固件

作用：

- 卡片里的签名逻辑
- 卡片侧的固件和相关文件

入口：

- [../card-applet/README.zh-CN.md](../card-applet/README.zh-CN.md)
- [J3R180 卡固件 Release 页面](https://github.com/akg5188/tp-satochip-signer/releases/tag/j3r180-card-firmware-20260318)

不要把它和树莓派固件、安卓 APK 混在一起理解。

### 2. `seedsigner-os`

这是：

- 树莓派固件

作用：

- 树莓派运行环境
- 设备系统和 UI
- 设备侧打包和镜像相关内容

入口：

- [../seedsigner-os/README.zh-CN.md](../seedsigner-os/README.zh-CN.md)
- [树莓派固件 Release 页面](https://github.com/akg5188/tp-satochip-signer/releases/tag/pi-signer-firmware-20260318)

### 3. `wallet`

这是：

- 独立钱包安卓工程

对应 APK：

- `satochip-wallet-release.apk`

作用：

- 独立观察钱包
- 资产、转账、签名、Hyperliquid

入口：

- [../wallet/README.md](../wallet/README.md)
- [独立钱包 Release 页面](https://github.com/akg5188/tp-satochip-signer/releases/tag/wallet-android-20260318-1717)

### 4. `app`

这是：

- 给 `TokenPocket` 商业钱包配合使用的安卓工程
- 中文名可以直接理解成“智能卡”

对应 APK：

- `tp-qr-relay-android-latest.apk`

作用：

- 专门做 TP 动态二维码中转签名
- 不是独立钱包

入口：

- [../app/README.md](../app/README.md)
- [TP 签名中转 Release 页面](https://github.com/akg5188/tp-satochip-signer/releases/tag/tp-relay-android-20260318-1956)

### 5. `backups/satochip-utils`

这是：

- `Satochip-Utils` 的离线备份
- 专门给 `J3R180` 卡设置 `PIN` 和助记词的桌面工具备份

作用：

- 在 `Tails OS` 里初始化卡
- 给卡设置 `PIN`
- 导入或生成 `BIP39` 助记词
- 作为上游工具仓库的离线恢复入口

注意：

- 这里不是卡固件
- 这里不是树莓派固件
- 这里不是安卓 APK

入口：

- [../backups/README.zh-CN.md](../backups/README.zh-CN.md)
- [../backups/satochip-utils/README.zh-CN.md](../backups/satochip-utils/README.zh-CN.md)
- [../backups/satochip-utils/Tails-离线使用教程.zh-CN.md](../backups/satochip-utils/Tails-离线使用教程.zh-CN.md)

## 两个安卓 APK 的区别

### `tp-qr-relay-android-latest.apk`

用途：

- 给 TP 商业钱包用
- 做扫码中转签名
- 对应源码在 `app/`

### `satochip-wallet-release.apk`

用途：

- 独立钱包
- 自己看资产、转账、连 Hyperliquid
- 对应源码在 `wallet/`

## 推荐记忆法

- 卡片相关看 `card-applet`
- 树莓派相关看 `seedsigner-os`
- 独立钱包看 `wallet`
- TP 配套安卓软件看 `app`
- `PIN` / 助记词初始化工具看 `backups/satochip-utils`
