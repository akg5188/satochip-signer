# 长期维护总入口

这份文档是整个项目的总导航。

以后时间久了，只要先看这一篇，就能重新找到：

- 下载入口
- 固件入口
- 编译命令
- 发布路径
- 更新顺序

## 1. 先记住五个部分

- `card-applet`
  `J3R180` 智能卡固件
- `seedsigner-os`
  树莓派固件源码
- `wallet`
  独立钱包安卓工程
- `app`
  配合 `TokenPocket` 使用的“智能卡”安卓工程
- `backups/satochip-utils`
  在 `Tails OS` 里设置 `PIN` 和助记词的离线工具备份

## 3. 重新编译时看哪里

### 3.1 独立钱包 `wallet`

```bash
cd wallet
cp local.properties.example local.properties
./gradlew assembleRelease --console=plain
```

输出：

```text
wallet/app/build/outputs/apk/release/app-release.apk
```

### 3.2 TP 安卓工程 `app`

```bash
cp local.properties.example local.properties
./gradlew :app:assembleRelease --console=plain
```

输出：

```text
app/build/outputs/apk/release/app-release.apk
```

### 3.3 J3R180 卡固件

优先直接用预编译文件：

```text
card-applet/prebuilt/SatoChip-3.0.4.cap
```

如果要自己编译：

```bash
cd card-applet/SatochipApplet
ant
```

### 3.4 树莓派固件

如果只是用现成镜像，不需要编译，直接烧录：

```text
dist/system-update-latest.img.xz
```

如果要重打镜像，优先看：

- [维护说明](维护说明.zh-CN.md)
- `scripts/repack_runtime_image.sh`
- `scripts/build_pi_release.sh`

## 4. 发布和校验时要做什么

### 安卓 APK

- 重新编译
- 生成 `sha256`
- 上传到 GitHub Release

### 卡固件

- 检查 `card-applet/prebuilt/SHA256SUMS.txt`
- 上传 `cap` 和 `SHA256SUMS.txt`

### 树莓派固件

- 检查 `dist/system-update-latest.img.xz.sha256`
- 上传镜像和校验文件

## 5. 最容易踩坑的地方

- `local.properties` 只应该是本地文件，不要长期依赖某一台机器路径
- 安卓构建如果遇到 Google Maven 解析异常，先看 `settings.gradle.kts` 里的镜像源配置
- 需要长期稳定保存的产物，优先保留：
  `latest` 命名文件 + `sha256` + GitHub Release
- `Tails OS` 下卡初始化工具要记得把缩放调成 `100%`
