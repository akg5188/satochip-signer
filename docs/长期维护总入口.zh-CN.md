# 长期维护总入口

这份文档是整个仓库的长期维护总导航。

以后时间久了，只要先看这一页，就能重新找到：

- 该刷哪张树莓派镜像
- 哪个安卓 APK 负责什么
- 哪条构建命令是正式入口
- 源码和固件怎么对应
- 发布页里哪个是当前推荐、哪个只是历史归档

## 1. 当前仓库的 5 个部分

| 部分 | 目录 | 当前用途 |
| --- | --- | --- |
| 树莓派离线签名器 | `seedsigner-os/` | 离线签名器系统与 UI |
| 安卓“智能卡”App | `app/` | `TokenPocket` 请求扫码、智能卡签名、可选树莓派中转 |
| 安卓观察钱包 | `wallet/` | 高安全观察钱包 + `WalletConnect` + `BTC` 观察账户原型 |
| 智能卡固件 | `card-applet/` | `J3R180` 卡固件 |
| 离线初始化工具 | `backups/satochip-utils/` | `Tails` 下设 PIN、导助记词 |

## 2. 当前最常用下载入口

### 树莓派镜像

- 当前推荐 clean 正式版：
  `dist/system-update-latest.img.xz`
- 历史功能备份：
  `dist/system-update-offline-signer-review-pinless.img.xz`

### 钱包 APK

- `dist/satochip-wallet-release.apk`

### 智能卡 App

- 通过 `bash scripts/build_tp_relay_apk.sh` 现编

### `J3R180` 卡固件

- `card-applet/prebuilt/SatoChip-3.0.4.cap`

## 3. 当前正式构建入口

### 树莓派

```bash
bash scripts/build_pi_firmware_from_snapshot.sh
bash scripts/check_release_artifacts.sh
```

### 安卓“智能卡”App

```bash
bash scripts/build_tp_relay_apk.sh
```

### 安卓观察钱包

```bash
bash scripts/build_wallet_release.sh
```

## 5. 以后发版时最稳的顺序

1. 改源码
2. 改文档
3. 提交源码和文档
4. 在干净提交上重新构建
5. 生成或校验 `sha256`
6. 再提交 `dist/` 产物
7. 最后推 GitHub 与 Release
