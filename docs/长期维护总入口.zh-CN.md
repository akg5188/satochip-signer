# 长期维护总入口

这份文档是整个仓库的长期维护总导航。

以后时间久了，只要先看这一页，就能重新找到：

- 该刷哪张树莓派镜像
- 哪个安卓 APK 负责什么
- 哪条构建命令是正式入口
- 源码和固件怎么对应
- 发布页里哪个是当前推荐、哪个只是历史归档
- 官方下载文件该怎么验真

## 1. 当前仓库的 4 条主线

| 部分 | 目录 | 当前用途 |
| --- | --- | --- |
| 树莓派离线签名器 | `seedsigner-os/` | 离线签名器系统与 UI |
| 安卓“智能卡”App | `app/` | `TokenPocket` 请求扫码、智能卡签名、可选树莓派中转 |
| 安卓观察钱包 | `wallet/` | 高安全观察钱包 + `WalletConnect` + `BTC` 观察账户原型 + `OKX Wallet / Bitget Wallet` Web3 桥接 |
| 离线初始化工具备份 | `backups/satochip-utils/` | `Tails` 下设 PIN、导助记词 |

## 2. 当前正式发布件统一重建入口

```bash
bash scripts/rebuild_official_release.sh --list
bash scripts/rebuild_official_release.sh firmware-clean
bash scripts/rebuild_official_release.sh wallet-release
```

这套入口里，`firmware-clean` 和 `wallet-release` 现在都跟随当前 `HEAD`，不再回到旧固件 / 旧钱包 tag。

## 3. 当前最常用下载入口

### 树莓派镜像

- 当前 clean 基线产物：
  `dist/system-update-latest.img.xz`
- 当前工作区测试产物：
  `dist/system-update-worktree-latest.img.xz`
- GitHub 当前公开下载固件：
  `offline-signer-firmware-20260410b-clean`
- 当前 `firmware-clean` 源码来源：
  `HEAD`
- 历史 `20260410b` 冻结源码：
  `offline-signer-clean-source-20260410b`
- 如果卡里已经同时装了 `SeedKeeper` 和 `SatochipApplet`，当前主线固件已经能直接分别进入两条功能，不需要再来回重刷

### 钱包 APK

- `dist/satochip-wallet-worktree-latest.apk`
- 当前工作区最新测试包
- `dist/satochip-wallet-release.apk`
- 当前 clean 正式版：
  `wallet-release -> HEAD`
- 公开下载入口统一看：
  [版本时间线与发布入口](版本时间线与发布入口.zh-CN.md)

### 智能卡 App

- 通过 `bash scripts/build_tp_relay_apk.sh` 现编
- 这组 APK 默认按需构建，不保证长期常驻仓库 `dist/`
- 当前公开 tag 统一看：
  [版本时间线与发布入口](版本时间线与发布入口.zh-CN.md)

### 官方智能卡程序

- 本仓库不再维护 `J3R180 / SatochipApplet` 预编译 `CAP`
- 统一改用上游官方 release
- 固定下载、文件名和校验统一看：
  [官方程序下载验真与校验](官方程序下载验真与校验.zh-CN.md)

## 4. 当前正式构建入口

### 树莓派

```bash
bash scripts/rebuild_official_release.sh firmware-clean
bash scripts/build_current_firmware.sh
bash scripts/check_release_artifacts.sh
```

规则记法：

- `firmware-clean`：clean `HEAD`，输出 `system-update-latest.*`
- `build_current_firmware.sh`：当前工作区测试包，默认输出 `system-update-worktree-latest.*`

### 安卓“智能卡”App

```bash
bash scripts/build_tp_relay_apk.sh
```

### 安卓观察钱包

```bash
bash scripts/build_current_wallet_apk.sh
bash scripts/rebuild_official_release.sh wallet-release
```

## 5. 当前最重要的映射关系

### clean 正式基线

- 镜像：
  `system-update-latest.img.xz`
- 当前 clean 固件入口：
  `firmware-clean -> HEAD`
- 当前工作区测试包：
  `system-update-worktree-latest.img.xz`
- 历史公开固件：
  `firmware-public-20260410b-clean -> offline-signer-clean-source-20260410b`

## 6. 以后发版时最稳的顺序

1. 改源码
2. 改文档
3. 提交源码和文档
4. 在干净提交上重新构建
5. 生成或校验 `sha256`
6. 再提交 `dist/` 产物
7. 最后推 GitHub 与 Release
