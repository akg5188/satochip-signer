# 长期维护总入口

这份文档是整个仓库的长期维护总导航。

以后时间久了，只要先看这一页，就能重新找到：

- 该刷哪张树莓派镜像
- 哪个安卓 APK 负责什么
- 哪条构建命令是正式入口
- 源码和固件怎么对应
- 发布页里哪个是当前推荐、哪个只是历史归档
- 官方下载文件该怎么验真

## 1. 当前仓库的 4 条主线

| 部分 | 目录 | 当前用途 |
| --- | --- | --- |
| 树莓派离线签名器 | `seedsigner-os/` | 离线签名器系统与 UI |
| 安卓“智能卡”App | `app/` | `TokenPocket` 请求扫码、智能卡签名、可选树莓派中转 |
| 安卓观察钱包 | `wallet/` | 高安全观察钱包 + `WalletConnect` + `BTC` 观察账户原型 |
| 离线初始化工具备份 | `backups/satochip-utils/` | `Tails` 下设 PIN、导助记词 |

## 2. 当前正式发布件统一重建入口

```bash
bash scripts/rebuild_official_release.sh --list
bash scripts/rebuild_official_release.sh firmware-clean
bash scripts/rebuild_official_release.sh wallet-release
```

这套入口会自动去找官方 `source tag`，不要再手动猜。

## 3. 当前最常用下载入口

### 树莓派镜像

- 当前这台电脑里最新可刷的测试固件：
  `dist/system-update-card-entropy-test.img.xz`
- GitHub 当前公开下载固件：
  `offline-signer-firmware-20260405-seedkeeper-suite-current`
- 当前 clean 复现基线：
  `dist/system-update-latest.img.xz`
- 如果卡里已经同时装了 `SeedKeeper` 和 `SatochipApplet`，当前推荐固件已经能直接分别进入两条功能，不需要再来回重刷

### 钱包 APK

- `dist/satochip-wallet-release.apk`

### 智能卡 App

- 通过 `bash scripts/build_tp_relay_apk.sh` 现编

### 官方智能卡程序

- 本仓库不再维护 `J3R180 / SatochipApplet` 预编译 `CAP`
- 统一改用上游官方 release
- 固定下载、文件名和校验统一看：
  [官方程序下载验真与校验](官方程序下载验真与校验.zh-CN.md)

## 6. 以后发版时最稳的顺序

1. 改源码
2. 改文档
3. 提交源码和文档
4. 在干净提交上重新构建
5. 生成或校验 `sha256`
6. 再提交 `dist/` 产物
7. 最后推 GitHub 与 Release
