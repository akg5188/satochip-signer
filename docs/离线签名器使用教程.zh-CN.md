# 离线签名器使用教程

这份教程按当前固件的真实菜单重写，只讲现在设备上真的有、真的能走通的功能。

如果你只想先把机器刷起来，先看：

如果你已经刷好机，准备深入用这套固件，优先搭配这 3 份教程一起看：

- [离线熵创建助记词教程](离线熵创建助记词教程.zh-CN.md)

## 1. 开机后先看到什么

当前固件开机不会直接进主页，而是先看到：

- `设备登录`

第一次刷机后会先设置 `4-12` 位数字登录密码。以后每次开机都先输这个密码，才会进入真正的主界面。

登录通过后，首页标题是：

- `离线签名器`

首页 4 个入口是：

- `扫码签名`
- `助记词工具`
- `固件完整性自检`
- `智能卡工具`

如果你只是想正常使用，不要从“完整智能卡菜单”之类的深层页面开始，先按首页这 4 个入口走。

## 2. 先记住这 4 条总原则

1. 当前所有“查看助记词”的标准核对页，优先看 `查看 BIP39 序号`。旧教程里那种单独找“查看助记词”的说法，现在都以 `查看 BIP39 序号` 为准。
2. `SeedKeeper` 和 `SatochipApplet` 不是同一个 applet。更稳的长期方案仍然是：一张 `SeedKeeper` 专用卡，一张 `SatochipApplet` 专用卡。
3. `BIP85` 子助记词和“二次加密后的假助记词”不是同一个东西。前者是标准 `BIP39` 子钱包，后者是为了额外隐藏真助记词而做的中间结果。
4. 钛板直备份和“钢板数字/二次加密”也是两条不同路线。标准 `BIP39` 直备份优先看 [钛板打孔备份助记词教程](钛板打孔备份助记词教程.zh-CN.md)。

## 3. `扫码签名`

当前这条线主要服务 3 种场景：

- 自己的安卓观察钱包
- `BlueWallet` 的 `BTC PSBT`
- `TokenPocket` 中转场景

最短流程都是一样的：

1. 手机或上游钱包显示待签名二维码
2. 树莓派进入 `扫码签名`
3. 固件解析交易或请求内容
4. 需要智能卡签名时输入卡 `PIN`
5. 树莓派显示签名结果二维码
6. 手机扫回并人工确认广播

如果输出是多张二维码，当前是“手动稳扫”逻辑：

- `右` 或右侧上面键：下一张
- `左` 或右侧中间键：上一张
- `上`：调亮
- `下`：调暗

## 4. `助记词工具`

当前菜单包括：

- `智能卡真随机创建助记词`
- `拍照创建助记词`
- `摇骰子创建助记词`
- `使用扑克牌创建助记词`
- `使用16进制创建助记词`
- `导入助记词`
- `BIP39 单词自检`
- `从钢板数字恢复二次助记词`
- `已加载助记词`

### 4.1 创建或导入助记词

现在最常用的入口有：

- `智能卡真随机创建助记词`
- `摇骰子创建助记词`
- `使用扑克牌创建助记词`
- `使用16进制创建助记词`
- 普通 `12 / 15 / 18 / 21 / 24` 词导入
- `按编号导入 BIP39 助记词`
- 扫描 `SeedQR`
- 从 `SeedKeeper` 导入

如果你要自己离线造随机数再生成助记词，这 3 条分别适合：

- `摇骰子创建助记词`
  固定次数最明确：`12/15/18/21/24` 词分别需要 `50/62/75/87/99` 次掷骰
- `使用扑克牌创建助记词`
  输入格式是 `AH QS 9D TC` 这种牌面串，更适合 `12/15/18/21` 词；单副 `52` 张牌不够做 `24` 词
- `使用16进制创建助记词`
  最快、最好核对，`12/15/18/21/24` 词分别需要 `32/40/48/56/64` 个 hex 字符

这 3 条的详细操作、数量表、和网站怎么逐项核对，单独看：

- [离线熵创建助记词教程](离线熵创建助记词教程.zh-CN.md)

如果你选的是：

- `按编号导入 BIP39 助记词`

那输入的是标准英文词表里的 `0-2047` 编号。导入完成后，后续核对页也会直接按 `查看 BIP39 序号` 这套版式显示，不再用旧的散乱查看页。

### 4.2 `BIP39 单词自检`

当前主要有两种查法：

- `输入单词查编号`
- `输入编号查单词`

这条线适合：

- 你手里只有数字编号备份
- 你想人工核对某个词到底是不是官方 `BIP39` 英文词表里的词

### 4.3 `已加载助记词`

助记词一旦加载进来，后面大多数操作都从这里继续。

常见入口包括：

- `查看 BIP39 序号`
- `查看原始熵(HEX)`
- `派生路径算地址`
- `导出当前助记词 BTC zpub`
- `导出当前助记词 BTC xpub`
- `BIP-85 子助记词`
- `写入当前助记词到智能卡`
- `写入当前助记词到 SeedKeeper`
- `二次加密助记词`
- `二次还原助记词`
- `转成钢板打孔数字`
- `删除助记词`

这里最关键的是：

- 真助记词现在统一优先看 `查看 BIP39 序号`
- 假助记词如果带有保存下来的原始编号，也会尽量按同一套编号页显示
- 需要人工复核时，不要只看单词，最好同时看编号

### 4.4 `查看原始熵(HEX)`

如果当前这条是标准英文 `BIP39` 助记词，还可以继续看：

- `查看原始熵(HEX)`

这串 `HEX` 是标准 `BIP39` 原始熵，不是骰子串，也不是你自己定义的编号串。

它适合做两件事：

- 用手机扫二维码再次留档
- 放到支持 `BIP39 entropy/HEX` 的工具里做独立复核

### 4.5 `BIP-85 子助记词`

这条功能现在是正式主流程，不是实验入口了。

路径：

- `已加载助记词 -> BIP-85 子助记词`

当前支持：

- 选择 `12 / 18 / 24` 词
- 输入 `BIP85 index`
- 查看子助记词
- 查看子助记词的 `BIP39` 序号
- `验证备份`
- `导入到树莓派`
- `子助记词写入智能卡`
- `子助记词写入 SeedKeeper`

这条线的详细用法单独看：

- [BIP85子助记词使用教程](BIP85子助记词使用教程.zh-CN.md)

### 4.6 二次加密 / 二次还原 / 钢板数字

这条线是为了把真助记词先变成“假的中间助记词”，再继续保存或转成钢板数字，不是标准 `BIP39` 直备份。

现在的实际流程是：

1. 先加载真助记词
2. 进入 `二次加密助记词`
3. 给每个词输入运算方式和数字
4. 得到一组假的助记词
5. 可以：
   - 继续 `查看 BIP39 序号`
   - `保存二次加密助记词到 SeedKeeper`
   - `转成钢板打孔数字`
6. 恢复时先：
   - `从钢板数字恢复二次助记词`
7. 最后再：
   - `二次还原助记词`

要特别记住：

- 从钢板数字恢复出来的，首先是“假助记词”
- 只有继续做 `二次还原助记词`，才会回到真助记词
- 当前运算符已经按字面执行：`+` 就是加，`-` 就是减

这条线和标准钛板直备份是两回事。要看完整区别和推荐用法，直接看：

- [钛板打孔备份助记词教程](钛板打孔备份助记词教程.zh-CN.md)

## 5. `智能卡工具`

当前顶层只保留 3 个入口：

- `Satochip 功能`
- `SeedKeeper 功能`
- `完整智能卡菜单`

日常使用优先点前两个。只有你真的要看更底层卡信息、描述符、克隆、容量之类的杂项时，才进：

- `完整智能卡菜单`

### 5.1 `Satochip 功能`

这条线偏签名卡，常用的是：

- `按路径查看 Satochip 地址`
- `导出 Satochip BTC zpub`
- `导出 Satochip BTC xpub`
- `写入已加载助记词到 Satochip`
- `更改 Satochip PIN`
- `重置 Satochip`

适合：

- 把当前助记词写成签名卡
- 直接看卡里派生出的地址或扩展公钥

### 5.2 `SeedKeeper 功能`

这条线偏秘密管理，常用的是：

- `卡上真随机创建助记词`
- `写入已加载助记词到 SeedKeeper`
- `保存二次加密助记词到 SeedKeeper`
- `从 SeedKeeper 加载二次加密助记词`
- `更改 SeedKeeper PIN`
- `重置 SeedKeeper`
- `更多 SeedKeeper 功能`

如果你进入：

- `智能卡工具 -> SeedKeeper 功能 -> 更多 SeedKeeper 功能 -> 查看和管理卡内助记词`

当前你应该看到的是：

- 真随机助记词
- 普通写入的助记词
- 助记词标签里带指纹，方便你分辨

而不是：

- 二次加密假助记词缓存
- 各种描述符、密码、杂项秘密全部混在同一个列表里

### 5.3 假助记词保存到 `SeedKeeper`

如果你已经做完二次加密，现在可以把假助记词再留一份卡内备份：

- `保存二次加密助记词到 SeedKeeper`

以后恢复时，从这里读回来：

- `从 SeedKeeper 加载二次加密助记词`

再继续：

- `查看 BIP39 序号`
- `转成钢板打孔数字`
- `二次还原助记词`

### 5.4 `SeedKeeper` 真随机创建助记词

现在有两条入口：

- `助记词工具 -> 智能卡真随机创建助记词`
- `智能卡工具 -> SeedKeeper 功能 -> 卡上真随机创建助记词`

两条最终都会把结果加载回树莓派的“已加载助记词”，后续你就能继续：

- `查看 BIP39 序号`
- `查看原始熵(HEX)`
- `写入当前助记词到智能卡`
- `写入当前助记词到 SeedKeeper`
- `BIP-85 子助记词`

## 6. `固件完整性自检`

这条功能适合做运行时自查，主要看：

- 关键文件是否缺失
- 关键文件是否被替换
- 是否多了不该有的额外文件

它适合发现“运行中的系统内容不对”，但不能单靠设备自己证明“整张卡绝对没被重刷”。

更稳的做法是一起看：

- 当前固件镜像的 `.sha256`
- 当前镜像的 `.build-info.txt`
- GitHub 上对应的源码和发布说明

## 7. 三条最常用的完整用法

### 7.1 日常直接签名

1. 刷固件
2. 设置登录密码
3. 准备 `Satochip` 签名卡
4. 进入 `扫码签名`
5. 用手机扫回签名结果

### 7.2 用一条主助记词派生很多子钱包

1. 创建或导入主助记词
2. 在 `已加载助记词` 里进入 `BIP-85 子助记词`
3. 记录好：
   - 主助记词身份
   - `BIP85 index`
   - 词数
4. 根据用途决定：
   - `导入到树莓派`
   - `子助记词写入智能卡`
   - `子助记词写入 SeedKeeper`

详细看：

- [BIP85子助记词使用教程](BIP85子助记词使用教程.zh-CN.md)

### 7.3 给正式资产做金属备份

如果你要的是“直接把标准 `BIP39` 助记词打到钛板上”，优先看：

- [钛板打孔备份助记词教程](钛板打孔备份助记词教程.zh-CN.md)

如果你要的是“先做二次加密假助记词，再把假助记词转成钢板数字/打孔位”，也看这份，因为里面已经把两条路线分开讲清楚了。

## 8. 常见误区

### 8.1 `BIP85` 子助记词和假助记词不是同一类

- `BIP85` 子助记词：标准 `BIP39` 子钱包
- 二次加密假助记词：为了隐藏真助记词而做的中间结果

### 8.2 `查看 BIP39 序号` 才是现在的标准核对页

如果你看到旧教程还在反复写“查看助记词”，按现在固件应改读成：

- `查看 BIP39 序号`

### 8.3 `SeedKeeper` 和 `SatochipApplet` 不该混成一张长期主力卡

可以临时共卡用，但不建议长期把重置、换密钥、恢复出厂这些高风险动作放在双 applet 共卡上做。

### 8.4 passphrase 不会自动出现在钛板或钢板里

如果你用的是 `BIP39 passphrase`：

- 它不在钛板里
- 它也不在标准助记词本体里
- 必须单独保存、单独演练恢复
