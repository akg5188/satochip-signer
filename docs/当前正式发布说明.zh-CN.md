## 1. 这次更新的重点

### 树莓派离线签名器

- 小屏页面重新排版，长内容优先改成摇杆上下滚动，减少硬拆分页
- 签名完成后先显示人能看懂的摘要，再决定是否显示二维码
- 写卡后自动回读核验，检查主指纹、`xpub / zpub`、首个地址和测试签名
- 修复 `查看助记词` 滚到底部容易被底部按钮贴住的问题
- 修复 `拍照创建助记词` 后查看原始熵不显示的问题

### 自动化测试

- 树莓派功能 smoke 扩到签名摘要、写卡核验、熵显示和二维码路径
- 新增桌面显示、按钮、相机、二维码 round-trip 和真实 UI 截图模拟
- 新增固件 Python 模块整包导入 smoke
- 发布前重新做了 clean 构建并核对正式 `sha256 / build-info`

## 3. 这次发布最重要的已知事项

- 当前这次正式发布只更新了树莓派固件，安卓正式钱包仍然保持 `wallet-android-20260408-0.1.4`
- 这台构建机上做的是宿主机/桌面模拟和 clean 构建校验，不是真树莓派全套实拍真机回归
- 官方 `BlueWallet` 现在已经能扫回树莓派返回的已签名交易
- 但对输入数较多的交易，`BlueWallet` 自己的广播页仍可能被长 `tx hex` 挤掉底部按钮

更稳的处理方式：

- 用自己的安卓观察钱包扫回并广播
- 或者在 `BlueWallet` 里复制 `tx hex`，再去别的广播器发
