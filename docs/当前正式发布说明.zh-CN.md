## 1. 这次更新的重点

### 树莓派离线签名器

- 修复 `BlueWallet` 扫回已签名 `BTC PSBT` 时的二维码兼容性
- 已签名 `PSBT` 会按输入格式回传，不再强行统一成单一路径
- `PSBT / 已签名交易` 二维码恢复优先使用自动动画输出，不再把连续扫描路径退回手动翻页
- 二维码显示尺寸改成跟随真实画布，不再写死 `240x240`

### 安卓观察钱包

- 主网 `BTC xpub / ypub / zpub` 同步改成优先走 `Electrum`
- 余额、`UTXO`、下一收款地址和最近活动的首轮同步明显更快
- `Electrum` 挂掉时会自动回退到原来的 HTTP 同步，不会直接把账户弄坏

### 自动化测试

- 树莓派功能 smoke 扩到 `BlueWallet / btctx / UR / BBQR / BASE64 / SPECTER`
- 新增桌面显示、按钮、相机、二维码 round-trip 模拟
- 新增固件 Python 模块整包导入 smoke
- 新增本地 mock `Electrum` 集成测试，真实覆盖钱包同步主路径

## 3. 这次发布最重要的已知事项

- 官方 `BlueWallet` 现在已经能扫回树莓派返回的已签名交易
- 但对输入数较多的交易，`BlueWallet` 自己的广播页可能会因为长 `tx hex` 把底部按钮挤出屏幕
- 这种情况不是固件签名失败，而是 `BlueWallet` 客户端页面布局问题

更稳的处理方式：

- 用自己的安卓观察钱包扫回并广播
- 或者在 `BlueWallet` 里复制 `tx hex`，再去别的广播器发
