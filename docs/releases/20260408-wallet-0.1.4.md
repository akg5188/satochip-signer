# wallet-android-20260408-0.1.4

本次正式钱包重点更新：

- 主网 `BTC xpub / ypub / zpub` 同步优先走 `Electrum`
- 首轮同步更快返回余额、`UTXO`、下一收款地址和最近活动
- `Electrum` 不可用时自动回退到旧 HTTP 路线
- 新增本地 mock `Electrum` 集成测试，直接覆盖钱包同步主路径

配套固件建议使用：

- `offline-signer-firmware-20260408-clean`

建议安装前先看：

- `wallet/README.md`
- `wallet/docs/使用教程.zh-CN.md`
- `docs/版本时间线与发布入口.zh-CN.md`

已知事项：

- 这是观察钱包，不是热钱包；手机里不存私钥
- 如果你之前装的是旧签名 key 对应的钱包包名版本，可能需要先卸载旧包再装新包
