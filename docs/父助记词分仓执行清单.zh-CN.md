# 父助记词分仓执行清单

这份清单不是讲原理的。

它只做一件事：

- 让你在真正操作时，按顺序一项一项打勾

配套长文看这里：

- [父助记词分仓到多张子卡操作手册](父助记词分仓到多张子卡操作手册.zh-CN.md)
- [BIP85子助记词使用教程](BIP85子助记词使用教程.zh-CN.md)
- [父助记词分仓模板-3张卡](父助记词分仓模板-3张卡.zh-CN.md)
- [父助记词分仓模板-4张卡](父助记词分仓模板-4张卡.zh-CN.md)

## 0. 先确认总原则

- [ ] 父助记词不会写进便宜白卡
- [ ] 白卡只写子助记词
- [ ] 每张卡只负责一个子仓
- [ ] 每张卡只放我能承受损失的金额

## 1. 先把仓位设计好

- [ ] 我已经决定这次要分几仓
- [ ] 我已经给每一仓定好用途
- [ ] 我已经决定每一仓大概放多少钱
- [ ] 我已经给每一张卡起好名字

推荐命名：

- `日常卡`
- `备用卡`
- `测试卡`
- `实验卡`

## 2. 先把 index 规划好

- [ ] 我已经给每个子仓固定 `index`
- [ ] 我不会临时乱换 `index`
- [ ] 我已经把 `index` 和用途写到离线记录里

推荐最简单方案：

```text
index 0：日常卡
index 1：备用卡
index 2：测试卡
index 3：实验卡
```

## 3. 先准备离线记录纸

- [ ] 我准备了一张单独离线记录纸
- [ ] 上面写了父助记词标签
- [ ] 上面写了每张卡的用途
- [ ] 上面写了每张卡对应的 `index`

离线记录纸只建议写：

```text
父助记词标签：总种子-主备份
A：日常卡 / index 0
B：备用卡 / index 1
C：测试卡 / index 2
D：实验卡 / index 3
```

离线记录纸不要写：

- 完整助记词
- PIN
- 全部金额

## 4. 开始派生第 1 张子卡前

- [ ] 我已经把父助记词加载进树莓派
- [ ] 我确认当前加载的是正确那条父助记词
- [ ] 我知道这张卡对应哪个用途
- [ ] 我知道这张卡对应哪个 `index`

## 5. 树莓派里实际操作

路径：

`助记词工具 -> 已加载助记词 -> BIP-85 子助记词`

本轮操作时逐项确认：

- [ ] 我已经进入 `BIP-85 子助记词`
- [ ] 我已经选好词数
- [ ] 我输入的是这张卡固定使用的 `index`
- [ ] 我已经看过生成结果
- [ ] 我确认这次不是把父助记词直接写进卡

## 6. 写卡前最后确认

- [ ] 我拿的是正确那张卡
- [ ] 我已经确认这张卡用途标签没弄错
- [ ] 我知道这张卡之后准备放多少钱
- [ ] 这不是测试卡和正式卡混用

## 7. 写卡后自动核验

写完以后，不要只看“写入成功”。

至少确认下面这些都通过：

- [ ] 主指纹一致
- [ ] `xpub / zpub` 一致
- [ ] 收款地址一致
- [ ] 找零地址一致
- [ ] 测试签名验签通过

如果这里有任何一项失败：

- [ ] 立刻停止把正式资金放进这张卡

## 8. 拔卡重插复验

- [ ] 我已经拔卡重插一次
- [ ] 我已经再次读取公开信息
- [ ] 第二次结果仍然一致

## 9. 小额实测

- [ ] 我只用极小金额做第一次测试
- [ ] 我已经让这张卡完成过一次真实签名
- [ ] 我已经看过签名摘要页
- [ ] 摘要页显示没有明显异常

签名摘要页至少看：

- [ ] 金额对
- [ ] 手续费对
- [ ] 地址对
- [ ] `重复r: 未发现`
- [ ] `低S: 通过`

## 10. 正式入金前

- [ ] 我已经确认这张卡不是第一次就大额入金
- [ ] 我已经确认这张卡用途和金额等级匹配
- [ ] 我已经确认测试卡不会混进正式资金

## 11. 每张卡写完后都重复一遍

给每张卡都单独打勾：

### 日常卡

- [ ] 已派生
- [ ] 已写卡
- [ ] 已核验
- [ ] 已小额实测

### 备用卡

- [ ] 已派生
- [ ] 已写卡
- [ ] 已核验
- [ ] 已小额实测

### 测试卡

- [ ] 已派生
- [ ] 已写卡
- [ ] 已核验
- [ ] 已小额实测

### 实验卡

- [ ] 已派生
- [ ] 已写卡
- [ ] 已核验
- [ ] 已小额实测

## 12. 父助记词最终检查

- [ ] 父助记词没有写进便宜白卡
- [ ] 父助记词没有放进联网手机
- [ ] 父助记词备份位置和子卡分开
- [ ] 我自己以后还能认出这条父助记词是谁

## 13. 一句话收尾检查

只要下面 4 条都满足，这轮分仓就算完成：

- [ ] 父助记词没进白卡
- [ ] 每张卡只装一个子仓
- [ ] 每张卡都做过回读核验
- [ ] 每张卡都做过小额实测
