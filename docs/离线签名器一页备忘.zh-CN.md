- `设备登录`

第一次会设置 `4-12` 位数字登录密码；以后开机先输它，再进入主页。

- `离线签名器`

- `扫码签名`
- `助记词工具`

## 3. 两条默认派生路径

- EVM：
  `m/44'/60'/0'/0/0`
- BTC 单地址查看：
  `m/84'/0'/0'/0/0`

## 4. 二维码页怎么按

多张手动切换页：

- `右` 或右侧上面键：下一张
- `左` 或右侧中间键：上一张
- `上`：调亮
- `下`：调暗
- 其他确认键：退出

## 5. 固件自检怎么看

它会检查：

- 关键文件是否缺失
- 关键文件是否被改
- 是否被额外塞了不该有的文件

它不能单独证明“整张卡绝对没被重刷”。

如果要更稳，还要对照：

- 当前镜像的 `.sha256`
- 当前镜像的 `.build-info.txt`
- GitHub 上对应的 `build-info` / 源码 tag

## 6. 最常用 3 个功能入口

### 助记词工具

可以做：

- `创建助记词`
- `创建助记词 -> 扑克牌创建`
- `创建助记词 -> 16进制创建`
- `创建助记词 -> 骰子创建`
- `创建助记词 -> 拍照创建`
- `创建助记词 -> 智能卡创建`
- 导入助记词
- `BIP39` 单词自检
- 从钢板数字恢复二次助记词
- 已加载助记词管理

离线造随机数这 3 条最短记法：

- 骰子：
  `12/15/18/21/24` 词 = `50/62/75/87/99` 次
- 扑克牌：
  建议至少 `32/38/44/51` 张分别对应 `12/15/18/21` 词；单副 `52` 张牌不够做 `24` 词
- 16进制：
  `12/15/18/21/24` 词 = `32/40/48/56/64` 个 hex 字符

人工复核时优先看：

- `查看 BIP39 序号`
- `查看原始熵`
- `显示二维码`

### 智能卡工具

可以做：

- `助记词工具 -> 创建助记词 -> 智能卡创建`
- `Satochip 功能`
- `SeedKeeper 功能`
- `完整智能卡菜单`

### 扫码签名

当前已接入：

- 自有安卓钱包请求
- `BlueWallet BTC PSBT`
- `TokenPocket` 直接扫码请求
