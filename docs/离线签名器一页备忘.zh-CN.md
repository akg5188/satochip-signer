- `设备登录`

第一次会设置 `4-12` 位数字登录密码；以后开机先输它，再进入主页。

标题：

- `离线签名器`

菜单：

- `扫码签名`
- `助记词工具`
- `固件完整性自检`

## 3. 两条默认派生路径

- EVM：
  `m/44'/60'/0'/0/0`
- BTC 单地址查看：
  `m/84'/0'/0'/0/0`

## 4. 二维码页怎么按

多张手动切换页：

- `右` 或右侧上面键：下一张
- `左` 或右侧中间键：上一张
- `上`：调亮
- `下`：调暗
- 其他确认键：退出

## 5. 固件完整性自检怎么看

它会检查：

- 关键文件是否缺失
- 关键文件是否被改
- 是否被额外塞了不该有的文件

它不能单独证明“整张卡绝对没被重刷”。

如果要更稳，还要对照：

- 当前镜像的 `.sha256`
- 当前镜像的 `.build-info.txt`
- GitHub 上对应的源码提交说明

## 6. 最常用 3 个功能入口

### 助记词工具

可以做：

- 拍照创建助记词
- 摇骰子创建助记词
- 导入助记词
- `BIP39` 单词自检
- 从钢板数字恢复二次助记词
- 已加载助记词管理

已加载助记词里还可以做：

- `查看原始熵(HEX)`
- `BIP-85 子助记词`
- 子助记词查看与备份验证
- 直接把当前助记词写入智能卡
- 直接把当前助记词写入 SeedKeeper
- 完成子助记词后继续做二次加密、钢板数字转换等
- 默认创建的助记词是标准 `BIP39`，可直接当 `BIP85` 父助记词
- 子助记词技术上还能继续当父助记词，但长期管理更推荐固定 1 条主父助记词，用不同 `index` 派生，不要层层套娃
- 导入助记词时也支持 `按编号导入 BIP39 助记词`

人工复核时优先看：

- `查看助记词`
- `查看 BIP39 序号`
- `查看原始熵(HEX)`
- `显示二维码`

同一份 `HEX` 熵，如果放进 `BIP39` 网站的原始熵输入框，生成出来的助记词会一样。
注意不是网站的 `Dice` 模式。

钢板数字恢复时：

- 每个词一组数字
- 组内用空格分开
- 树莓派会自动求和成 `0-2047`
- 右侧上面键：空格
- 右侧中间键：退格
- 输完后可用 `编辑当前页` 改错字，不用整份重输

### 智能卡工具

可以做：

- `助记词工具 -> 智能卡真随机创建助记词`
- `Satochip 功能`
- `SeedKeeper 功能`
- `完整智能卡菜单`

`Satochip 功能` 里主要是：

- 按路径查看 `Satochip` 地址
- 导出 `Satochip BTC zpub/xpub`
- 写入已加载助记词到 `Satochip`
- 更改 `Satochip PIN`
- 重置 `Satochip`

`SeedKeeper 功能` 里主要是：

- 卡上真随机创建助记词
- 写入已加载助记词到 `SeedKeeper`
- 保存二次加密助记词到 `SeedKeeper`
- 从 `SeedKeeper` 加载二次加密助记词
- 更改 `SeedKeeper PIN`
- 重置 `SeedKeeper`

`SeedKeeper` 真随机创建助记词后，继续在已加载助记词里就能：

- `查看助记词`
- `查看 BIP39 序号`
- `查看原始熵(HEX)`
- `显示二维码`
- `写入当前助记词到 Satochip`
- `写入当前助记词到 SeedKeeper`

如果你把“二次加密后的假助记词”保存进了 `SeedKeeper`，以后可以直接从：

- `智能卡工具 -> SeedKeeper 功能 -> 从 SeedKeeper 加载二次加密助记词`

把它读回树莓派，继续做钢板数字和二次还原。这个列表现在只显示成 `假助记词缓存 01/02...`，不会把内部标签直接露出来。

卡片分工记住：

- `SeedKeeper` 和 `SatochipApplet` 不是同一个东西
- 同一张 `J3R180` 卡也可以同时装两个 applet
- 当前树莓派固件不能直接给卡刷 applet
- 官方 `SeedSigner` 固件也不能直接来回切换这两种 applet
- 如果 `gp.jar --list` 已经能同时看到两个 `APP`，就直接用现状，不要再为了切换功能重刷
