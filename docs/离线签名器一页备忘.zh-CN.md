## 4. 二维码页怎么按

多张手动切换页：

- `右` 或右侧上面键：下一张
- `左` 或右侧中间键：上一张
- `上`：调亮
- `下`：调暗
- 其他确认键：退出

## 5. 固件完整性自检怎么看

它会检查：

- 关键文件是否缺失
- 关键文件是否被改
- 是否被额外塞了不该有的文件

它不能单独证明“整张卡绝对没被重刷”。

如果要更稳，还要对照：

- 当前镜像的 `.sha256`
- 当前镜像的 `.build-info.txt`
- GitHub 上对应的源码 tag

## 6. 最常用 3 个功能入口

### 助记词工具

可以做：

- 拍照创建助记词
- 摇骰子创建助记词
- 导入助记词
- `BIP39` 单词自检
- 从钢板数字恢复二次助记词
- 拍照识别钢板/纸张点位
- 已加载助记词管理

### 智能卡工具

可以做：

- 按路径查看智能卡地址
- 导出智能卡 `BTC zpub/xpub`
- 写入已加载助记词到智能卡
- 更改 `PIN`
- 重置智能卡

### 扫码签名

当前已接入：

- 自有安卓钱包请求
- `BlueWallet BTC PSBT`
- `TokenPocket` 中转请求
