# 树莓派签名器一页备忘

这页只保留最短、最容易忘、最需要固定的内容。

- 固件文件：`dist/system-update-latest.img.xz`
- 校验文件：`dist/system-update-latest.img.xz.sha256`
- 构建记录：`dist/system-update-latest.build-info.txt`

repo_head = f4f75ec85a7d4491b5ef16cda725899b8671a13e

## 2. 三种钱包分别怎么用

### 你自己的安卓钱包 `satochip-wallet-release.apk`

1. 手机显示待签名二维码
2. 树莓派进 `扫码签名`
3. 输入智能卡 `PIN`
4. 树莓派显示结果二维码
5. 手机扫回并广播

### BlueWallet

1. `BlueWallet` 显示 `BTC PSBT` 动画二维码
2. 树莓派进 `扫码签名`
3. 输入智能卡 `PIN`
4. 树莓派显示回传动画二维码
5. `BlueWallet` 扫回并广播

记住：

- `BlueWallet` 不走 TP 中转 App
- 这版已经兼容 `BBQR` 和 `URv2`

### TokenPocket

1. 先打开 `tp-qr-relay-android-latest.apk`
2. 先让中转 App 扫 `TokenPocket` 动态二维码
3. 中转 App 再给树莓派扫
4. 树莓派输入 `PIN` 签名
5. 手机扫回结果广播

记住：

- `TokenPocket` 必须先走中转 App

## 3. 树莓派二维码扫得慢怎么办

- 在二维码页面按硬件 `上` 键提亮
- 按硬件 `下` 键调暗
- 手机别贴太近，先稍远对焦
- 手机尽量正对屏幕，至少等完整一轮动画

## 4. 以后怎么确认没刷错包

先看 `dist/system-update-latest.build-info.txt`。

当前至少要确认：

- `repo_head` 是你预期的源码提交
- `repo_dirty=0`

从下一张按新流程重打的正式固件开始，还要额外确认：

- `build_clean_mode=clean`

只要这些条件对不上，就不要把那张镜像当正式稳定版。

## 5. 以后怎么重编尽量不漂移

先切固定标签：

```bash
git checkout pi-signer-firmware-20260329
```

正式稳定包只用：

```bash
bash scripts/build_pi_firmware_from_snapshot.sh
bash scripts/check_release_artifacts.sh
```

如果只是测试包，才显式用增量模式：

```bash
TP_BUILD_CLEAN_MODE=no-clean \
DIST_IMG=dist/system-update-test.img.xz \
DIST_SUM=dist/system-update-test.img.xz.sha256 \
DIST_INFO=dist/system-update-test.build-info.txt \
bash scripts/build_pi_firmware_from_snapshot.sh
```

记住：

- 正式稳定包必须是 `clean`
- `no-clean` 只给临时测试包
