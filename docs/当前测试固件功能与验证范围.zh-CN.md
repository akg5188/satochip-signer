## 2. 这次正式固件里应该能看到什么

### 核心修复

- `BlueWallet` 扫回已签名 `BTC PSBT` 的二维码兼容性修复
- 已签名 `PSBT` 按输入格式回传
- `PSBT / 已签名交易` 自动动画二维码恢复
- 二维码显示尺寸跟随真实画布

### 开机和主界面

- 第一次开机先看到：
  `设备登录`
- 首次要设置 `4-12` 位数字登录密码
- 首页 4 个入口：
  `扫码签名 / 助记词工具 / 固件完整性自检 / 智能卡工具`

### 助记词与智能卡

- `智能卡真随机创建助记词`
- `查看 BIP39 序号`
- `查看原始熵(HEX)`
- `显示二维码`
- `BIP-85 子助记词`
- `写入当前助记词到 Satochip`
- `写入当前助记词到 SeedKeeper`
- `保存二次加密助记词到 SeedKeeper`
- `从 SeedKeeper 加载二次加密助记词`

### 扫码签名

- 自有安卓钱包请求
- `BlueWallet BTC PSBT`
- `TokenPocket` 中转请求
