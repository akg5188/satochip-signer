## 2. 这次正式固件里应该能看到什么

### 核心修复

- 小屏 UI 排版收口，长内容优先改成摇杆上下滚动
- 签名完成后先显示摘要，再决定是否显示二维码
- 写卡后自动回读核验
- `查看助记词` 底部滚动留白修复
- `拍照创建助记词` 原始熵显示修复

### 开机和主界面

- 第一次开机先看到：
  `设备登录`
- 首次要设置 `4-12` 位数字登录密码
- 首页 4 个入口：
  `扫码签名 / 助记词工具 / 固件完整性自检 / 智能卡工具`

### 助记词与智能卡

- `智能卡真随机创建助记词`
- `查看 BIP39 序号`
- `查看原始熵`
- `显示二维码`
- `BIP-85 子助记词`
- `写入当前助记词到 Satochip`
- `写入当前助记词到 SeedKeeper`
- `保存二次加密助记词到 SeedKeeper`
- `从 SeedKeeper 加载二次加密助记词`

### 扫码签名

- 自有安卓钱包请求
- `BlueWallet BTC PSBT`
- `TokenPocket` 中转请求
