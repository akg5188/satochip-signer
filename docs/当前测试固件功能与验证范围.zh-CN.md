## 2. 这张固件里应该能看到什么

### 开机

- 第一次开机先看到：
  `设备登录`
- 首次要设置 `4-12` 位数字登录密码
- 以后每次开机都要先输入登录密码，才能进主页
- 登录配置文件 `offline-signer-login.json` 保存的是带盐值的 `PBKDF2` 哈希，不是明文密码
- 当前代码还会把这个文件权限收紧到 `600`

## 3. 已经过了什么检查

### 已通过

- 改动过的 Python 文件 `py_compile`
- `git diff --check`
- 菜单/数据路径烟测脚本
  - 智能卡主入口
  - `Satochip / SeedKeeper` 分流入口
  - `Javacard 刷卡工具` 中文按钮
  - `BIP85` 菜单标签
  - `SeedKeeper` 假助记词保存/加载的数据编码
  - `SeedKeeper` 友好标签
  - 助记词详情页只显示助记词本体
  - 开机登录密码哈希保存与校验
  - 登录密码文件权限为 `600`
- 固件镜像成功编出
- `sha256sum -c system-update-seedkeeper-suite-test.img.xz.sha256`

### 还没有替你做完整实体机逐项确认

- 真卡上 `SeedKeeper` 真随机生成助记词
- 真卡上 `更改 SeedKeeper PIN`
- 真卡上 `重置 SeedKeeper`
- 真卡上 “保存二次加密助记词到 SeedKeeper” 再重新加载
- 开机登录密码整条实体机输入流程

所以最准确的说法是：

- 代码级和烟测已经通过
- 固件已经成功编出
- 但不是所有智能卡相关路径都做过你这台设备上的实体机逐项验证

## 4. 你现在最该怎么试

建议你按这个顺序试，最不容易把自己绕晕：

1. 刷这张测试固件
2. 开机设置登录密码
3. 进 `助记词工具 -> 智能卡真随机创建助记词`
4. 进已加载助记词里看：
   - `查看助记词`
   - `查看 BIP39 序号`
   - `查看原始熵(HEX)`
   - `显示二维码`
5. 再进：
   - `智能卡工具 -> SeedKeeper 功能 -> 更多 SeedKeeper 功能 -> 查看和管理卡内秘密`
   - 看看列表是不是已经按 `真随机助记词 / 假助记词缓存` 这种更容易懂的方式显示
6. 再试：
   - `写入当前助记词到 Satochip`
   - `写入当前助记词到 SeedKeeper`
7. 最后再试：
   - `保存二次加密助记词到 SeedKeeper`
   - `从 SeedKeeper 加载二次加密助记词`
