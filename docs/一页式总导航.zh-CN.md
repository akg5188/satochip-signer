# 一页式总导航

这页只做一件事：帮你在忘光项目结构时，30 秒内找对入口。

如果你只想看树莓派那一块，先看：

- [离线签名器一页备忘](离线签名器一页备忘.zh-CN.md)

## 我现在要做什么

### 1. 我要刷树莓派固件

先看：

- [固件下载与写入指南](固件下载与写入指南.zh-CN.md)
- [固件与源码对应关系](固件与源码对应关系.zh-CN.md)
- [版本时间线与发布入口](版本时间线与发布入口.zh-CN.md)

当前要分清两张镜像：

- `dist/system-update-latest.img.xz`
  当前 clean 正式版，日常使用和复现都优先
- `dist/system-update-offline-signer-review-pinless.img.xz`
  历史功能备份，主要留给回滚排障

### 2. 我要让树莓派给自己钱包或 BlueWallet 签名

先看：

- [离线签名器使用教程](离线签名器使用教程.zh-CN.md)

你会用到树莓派首页的这些入口：

- `扫码签名`
- `助记词工具`
- `固件完整性自检`
- `智能卡工具`

### 3. 我要给 TokenPocket 做签名

先看：

- [../app/README.md](../app/README.md)
- [../app/docs/使用教程.zh-CN.md](../app/docs/使用教程.zh-CN.md)

`app/` 里的安卓“智能卡”App 现在可以做两件事：

- 手机上的 `TP` 请求扫码 + 智能卡直接签名
- 把 `TP` 动态码转成树莓派更容易扫的静态码

### 4. 我要用安卓观察钱包

先看：

- [../wallet/README.md](../wallet/README.md)
- [../wallet/docs/使用教程.zh-CN.md](../wallet/docs/使用教程.zh-CN.md)

当前 `wallet/` 的真实定位：

- `Arbitrum One` 高安全观察钱包
- `WalletConnect v2` 协调器
- `BTC xpub/ypub/zpub` 观察账户原型
- 树莓派离线签名请求生成与回签广播

不是：

- 热钱包
- 内置 `Hyperliquid` 浏览器

### 5. 我要初始化或重置智能卡

先看：

- [../backups/satochip-utils/Tails-离线使用教程.zh-CN.md](../backups/satochip-utils/Tails-离线使用教程.zh-CN.md)

### 6. 我要写智能卡固件

先看：

- [固件下载与写入指南](固件下载与写入指南.zh-CN.md)

## 五个核心目录

| 目录 | 当前用途 |
| --- | --- |
| `seedsigner-os/` | 树莓派离线签名器源码 |
| `app/` | `TokenPocket` 配套安卓智能卡签名/中转 App |
| `wallet/` | 安卓高安全观察钱包 |
| `card-applet/` | `J3R180` 智能卡固件 |
| `backups/satochip-utils/` | `Tails` 离线初始化工具 |

## 两个安卓 APK 怎么区分

| 文件 | 真实用途 |
| --- | --- |
| `tp-qr-relay-android-latest.apk` | `TokenPocket` 请求扫码、智能卡签名、可选树莓派中转 |
| `satochip-wallet-release.apk` | 观察钱包、`WalletConnect`、树莓派冷签、`BTC` 观察账户原型 |

`BlueWallet` 不是本仓库里的 APK。

## 三条最常用命令

```bash
bash scripts/build_pi_firmware_from_snapshot.sh
bash scripts/build_tp_relay_apk.sh
bash scripts/build_wallet_release.sh
```
