# 一页式总导航

这是一份给以后快速找路用的总导航。

如果时间久了忘了项目结构，不要先翻源码，先看这一页。

---

## 先问自己现在要做什么

### 1. 我要给 `TokenPocket` 商业钱包做签名中转

去这里：

- 工程目录：`app/`
- 使用说明：[../app/README.md](../app/README.md)
- 仓库稳定备份：
  `dist/tp-qr-relay-android-latest.apk`

你要装的包是：

- `tp-qr-relay-android-latest.apk`

它的作用是：

- 手机先扫 `TP` 动态二维码
- 手机再把中转二维码给树莓派扫
- 它不是独立钱包

### 2. 我要用独立钱包看资产、转账、用 `Hyperliquid`

去这里：

- 工程目录：`wallet/`
- 使用说明：[../wallet/README.md](../wallet/README.md)
- 标准构建入口：
  `bash scripts/build_wallet_release.sh`

你要装的包是：

- `satochip-wallet-release.apk`

它的作用是：

- `Arbitrum One` 观察钱包
- 资产查看
- 转账二维码签名
- 内置 `Hyperliquid`

### 3. 我要给 `J3R180` 卡设置 `PIN` 和助记词

去这里：

- 目录：`backups/satochip-utils/`
- 正式说明：[../backups/satochip-utils/README.zh-CN.md](../backups/satochip-utils/README.zh-CN.md)
- `Tails OS` 教程：
  [../backups/satochip-utils/Tails-离线使用教程.zh-CN.md](../backups/satochip-utils/Tails-离线使用教程.zh-CN.md)

它的作用是：

- 在 `Tails OS` 离线环境初始化卡
- 设置 `PIN`
- 导入或生成助记词

### 4. 我要给 `J3R180` 卡下载或写入卡固件

去这里：

- 固件目录：`card-applet/prebuilt/`
- 卡固件说明：[../card-applet/README.zh-CN.md](../card-applet/README.zh-CN.md)
- 固件下载与写入指南：[固件下载与写入指南](固件下载与写入指南.zh-CN.md)
- 固件 Release：
  `https://github.com/akg5188/tp-satochip-signer/releases/tag/j3r180-card-firmware-20260318`

你要找的固件是：

- `SatoChip-3.0.4.cap`

### 5. 我要给树莓派下载或写入固件

去这里：

- 固件目录：`dist/`
- 树莓派说明：[../seedsigner-os/README.zh-CN.md](../seedsigner-os/README.zh-CN.md)
- 固件下载与写入指南：[固件下载与写入指南](固件下载与写入指南.zh-CN.md)
- 树莓派使用教程：[树莓派签名器使用教程](树莓派签名器使用教程.zh-CN.md)
- GitHub Releases 页面：
  `https://github.com/akg5188/tp-satochip-signer/releases`

你要找的固件是：

- `system-update-latest.img.xz`

## 五个核心部分到底是什么

| 目录 | 它是什么 | 主要用途 |
| --- | --- | --- |
| `card-applet` | `J3R180` 智能卡固件 | 卡内签名逻辑 |
| `seedsigner-os` | 树莓派固件源码 | 树莓派系统和镜像 |
| `wallet` | 独立钱包安卓工程 | 观察钱包、资产、转账、`Hyperliquid` |
| `app` | TP 配套安卓工程 | 商业钱包签名中转 |
| `backups/satochip-utils` | 离线桌面工具备份 | 设 `PIN`、导助记词 |

## 最容易混的地方

- `app` 不是独立钱包，它只是给 `TokenPocket` 做签名中转。
- `wallet` 才是独立钱包，带资产页、转账和 `Hyperliquid`。
- `card-applet` 是卡固件，不是安卓程序。
- `seedsigner-os` 是树莓派固件，不是卡固件。
- `backups/satochip-utils` 是离线初始化工具，不是固件，也不是安卓 APK。

## 两个安卓 APK 不要混用

### `tp-qr-relay-android-latest.apk`

这是：

- 给 `TokenPocket` 商业钱包用的
- 扫码中转器

源码在：

- `app/`

### `satochip-wallet-release.apk`

这是：

- 独立钱包
- 带资产页、转账、签名和 `Hyperliquid`

源码在：

- `wallet/`

  `https://raw.githubusercontent.com/akg5188/tp-satochip-signer/main/dist/tp-qr-relay-android-latest.apk`
- `J3R180` 卡固件：
  `https://github.com/akg5188/tp-satochip-signer/releases/tag/j3r180-card-firmware-20260318`
- 树莓派固件：
  `https://raw.githubusercontent.com/akg5188/tp-satochip-signer/main/dist/system-update-latest.img.xz`

## 最短重新编译入口

### 重新编独立钱包

先看：
`docs/安卓构建环境准备.zh-CN.md`

```bash
bash scripts/build_wallet_release.sh
```

输出：

```text
dist/satochip-wallet-release.apk
```

### 重新编 TP 签名中转 App

先看：
`docs/安卓构建环境准备.zh-CN.md`

```bash
bash scripts/build_tp_relay_apk.sh
```

输出：

```text
dist/tp-qr-relay-android-latest.apk
```

### 重新生成树莓派运行时镜像

```bash
bash scripts/build_pi_firmware_from_snapshot.sh
```

### 卡固件优先直接用预编译文件

```text
card-applet/prebuilt/SatoChip-3.0.4.cap
```

## 最短维护顺序

1. 先看这一页，判断这次改的是哪一块。
2. 改完后先本地重新编译或重新打包。
3. 生成对应 `sha256`。
4. 同步更新仓库里的稳定文件名。
5. 上传到 GitHub Release。
6. 最后补文档。
