# 常用流程速查卡

这页不是完整教程，而是给你在真正操作时快速对照的。

适合：

- 你已经大概知道怎么回事
- 但真正要开始时，想看一份超短版步骤

如果你是完全第一次接触，先看：

- [零基础第一次上手教程](零基础第一次上手教程.zh-CN.md)
- [第一次小额测试完整流程](第一次小额测试完整流程.zh-CN.md)
- [父助记词分仓执行清单](父助记词分仓执行清单.zh-CN.md)

## 1. 自己的安卓观察钱包 -> 树莓派 -> 手机广播

适合：

- `Arbitrum`
- 自己的比特币观察钱包

最短步骤：

1. 手机上准备交易
2. 手机显示待签名二维码
3. 树莓派进 `扫码签名`
4. 树莓派核对内容
5. 输入智能卡 `PIN`
6. 树莓派先显示签名摘要
7. 确认后点 `显示签名二维码`
8. 手机扫回
9. 手机人工确认广播

开始前确认：

- 手机账户已经导入成功
- 卡是正确那张签名卡
- 你知道卡的 `PIN`

## 2. `BlueWallet` -> 树莓派 -> `BlueWallet` 广播

适合：

- 比特币 `PSBT` 冷签

最短步骤：

1. `BlueWallet` 发起交易
2. `BlueWallet` 显示 `PSBT` 二维码
3. 树莓派进 `扫码签名`
4. 输入智能卡 `PIN`
5. 树莓派先显示签名摘要
6. 确认后点 `显示签名二维码`
7. `BlueWallet` 扫回
8. `BlueWallet` 广播

如果广播页太长：

1. 先复制交易
2. 再去广播入口粘贴广播

## 3. `TokenPocket` -> 安卓智能卡 App -> 结果回 `TP`

适合：

- 手机直接配合智能卡签名

最短步骤：

1. `TokenPocket` 发起请求
2. 打开安卓“智能卡”App
3. 点 `扫码`
4. 扫 `TP` 请求二维码
5. 输入 `PIN`
6. 点 `解锁`
7. 核对摘要
8. 贴卡或插读卡器签名
9. 让 `TP` 扫回结果

## 4. `TokenPocket` -> 安卓智能卡 App -> 树莓派中转签名

适合：

- `TP` 动态码太快
- 树莓派直接扫不稳

最短步骤：

1. 安卓“智能卡”App 先扫 `TP` 动态码
2. App 生成树莓派静态中转二维码
3. 树莓派扫描静态码
4. 树莓派签名
5. 结果再回到手机

## 5. `OKX Wallet / Bitget Wallet` -> 安卓观察钱包 -> 树莓派

适合：

- Web3 钱包二维码太密，树莓派直接扫不稳
- 想用安卓观察钱包做二维码桥接

第一次连接：

1. 树莓派首页进 `连接钱包 -> Web3钱包`
2. 选择 `OKX钱包` 或 `Bitget钱包`
3. 选择 `智能卡账户` 或 `已加载助记词账户`
4. `OKX Wallet / Bitget Wallet` 添加 Keystone 硬件钱包并扫描树莓派连接码

签名：

1. Web3 钱包发起交易或签名
2. 安卓观察钱包进入 `DApp` 页并点 `扫描二维码`
3. 手机扫 Web3 钱包请求码
4. 手机显示树莓派中转码
5. 树莓派扫码签名
6. 树莓派直接显示原钱包可扫的结果码
7. Web3 钱包直接扫树莓派结果码

## 6. 每次开始前都先看这 5 条

1. 先确认你拿的是哪张卡
2. 先确认你知道卡的 `PIN`
3. 先确认金额是小额还是大额
4. 先确认地址是不是你想发去的地方
5. 先确认你现在走的是哪条链路
