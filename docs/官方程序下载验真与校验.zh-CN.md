# 官方程序下载验真与校验

这页只做一件事：

- 把当前项目会用到的上游官方程序、官方 CAP、以及本仓库固定产物的验真步骤写死

以后不要再靠“看起来像官方”“名字差不多”“latest 应该没问题”来判断。
最稳的顺序始终是：

1. 先核对仓库所有者和 release tag
2. 再核对资产文件名
3. 最后核对 `SHA256`
4. 验证通过后，把文件和校验清单一起离线归档

## 3. 复制粘贴就能用的下载与校验

```bash
mkdir -p ~/下载/官方程序校验
cd ~/下载/官方程序校验

wget -O gp.jar \
  https://github.com/martinpaljak/GlobalPlatformPro/releases/download/v25.10.20/gp.jar

wget -O SeedKeeper-v0.2-0.1.cap \
  https://github.com/Toporin/Seedkeeper-Applet/releases/download/v0.2-0.1/SeedKeeper-v0.2-0.1.cap

wget -O SeedKeeper-Ndef-v0.2-0.1.cap \
  https://github.com/Toporin/Seedkeeper-Applet/releases/download/v0.2-0.1/SeedKeeper-Ndef-v0.2-0.1.cap
```

把固定校验清单写进文件：

```bash
cat > SHA256SUMS.expected <<'EOF'
c88e0c5093032ec4571571f5397b6174e56bf632667950fa5bb716338534b122  gp.jar
28dbae3c7c130a6f7d0e6d05f41386ffd93976fd290eaa5d8db708b9903dabcd  SeedKeeper-v0.2-0.1.cap
ef776360415ee0c64881b1e36339ffba815231aab2406014559d18fdaa632c9b  SeedKeeper-Ndef-v0.2-0.1.cap
EOF
```

开始校验：

```bash
sha256sum -c SHA256SUMS.expected
```

只有全部显示 `OK` 才算这一步通过。

## 4. 验真时不要漏掉的 4 个点

### 4.1 先看仓库所有者

一定先核对：

- `martinpaljak/GlobalPlatformPro`
- `Toporin/Seedkeeper-Applet`
- `Toporin/SatochipApplet`
- `akg5188/satochip-signer`

不要只看文件名。

### 4.2 再看 release tag

不要无脑点 `latest`。
当前文档已经固定了版本号，就按固定 tag 下载。

### 4.3 再看资产文件名

最容易搞错的是：

- `SeedKeeper-v0.2-0.1.cap`
- `SeedKeeper-Ndef-v0.2-0.1.cap`
- `SatoChip-3.0.4.cap`
- `SatoChip-0.12-05.cap`

这些名字很像，但不是同一份文件。

### 4.4 最后才看 `SHA256`

`SHA256` 不对，就不要继续刷卡、刷 TF 卡、安装 APK。

## 5. 刷卡前先核对卡里已经装了什么

如果你是给 `J3R180` 卡装 applet，先跑：

```bash
java -jar gp.jar --list
```

常见关键输出：

- `APP: 5361746F4368697000 (SELECTABLE)`：`SatochipApplet`
- `APP: 536565644B656570657200 (SELECTABLE)`：`SeedKeeper`

如果这两条已经都在，就不要为了“切换功能”再重刷。

## 6. 验证通过后怎么保存

最稳的是把这些一起离线保存：

- 原始下载文件
- `SHA256SUMS.expected`
- 你自己执行 `sha256sum` 的终端输出截图或文本
- 对应 release 页截图

以后就算 GitHub 页面有变化，你也还有自己验证通过的一套离线归档。
