# 连接钱包教程

## 1. Web3 钱包：OKX / Bitget / MetaMask / Rabby / TokenPocket / Keystone

1. 树莓派首页进入 `连接钱包`
2. 选择 `Web3钱包`
3. 选择 `OKX钱包`、`Bitget钱包`、`MetaMask`、`Rabby` 或 `TokenPocket`
4. 选择 `智能卡账户` 或 `已加载助记词`
5. 树莓派显示连接二维码
6. 在对应钱包里添加 `Keystone` 硬件钱包并扫描

签名时：

1. 在 `OKX / Bitget / MetaMask / Rabby / TokenPocket / TP` 里发起转账或 DApp 签名
2. 如果原钱包二维码太密，安卓 App 点 `扫描钱包二维码并中转`
3. 安卓 App 扫原钱包二维码，并自动显示低密度中转二维码
4. 树莓派首页进入 `扫码签名`
5. 树莓派扫描安卓 App 的中转二维码
6. 树莓派核对摘要并确认签名
7. 树莓派显示 `eth-signature`
8. 原钱包直接扫回结果并广播或完成签名

说明：

- 安卓 App 不再生成 Web3 连接码，只做高密度二维码中转
- Bitget 的普通转账和 DApp 签名都走同一条回传协议
- OKX / Bitget / MetaMask / Rabby / TokenPocket 里请选择 Keystone 硬件钱包入口
- `MetaMask / Rabby / TokenPocket` 连接码走单张静态 `crypto-hdkey`
- `Bitget` 连接码走单张静态 `crypto-multi-accounts`，一个码里带 `ETH + BTC Native SegWit`
- `OKX` 连接码走动态 `crypto-multi-accounts`，包含 `ETH + 10 个 OKX EVM + BTC 49' + 84'`
- `Trust Wallet` 目前没有查到 Keystone 官方兼容页面，这个版本先不内置，避免你扫了半天还是不认
- 这里不是普通比特币观察钱包导入；Web3 连接码是 Keystone 兼容 `crypto-hdkey` 或 `crypto-multi-accounts`，签名请求/结果是 `eth-sign-request` / `eth-signature`
- `eth-signature` 看起来会是一长串英文 UR，不是直接广播 hex；原钱包扫回后才负责组装交易和广播

`Bitget / TokenPocket` 高密度签名码当前备用办法：

1. 先让钱包把待签名二维码完整显示出来，并录屏几秒
2. 打开相册播放这段录屏
3. 双指适度放大，让二维码尽量铺满屏幕，但四边不要被裁掉
4. 保持亮度较高，再让树莓派或安卓中转 App 去扫这段录屏

注意：

- 如果是动态二维码，不要截图成单张，要让录屏里的二维码完整循环播放
- 这个办法适合 `Bitget / TokenPocket` 当前仍偏密的签名请求码
- 实测更换 `120` 度摄像头后，`OKX / MetaMask / Rabby` 大多可直接扫描

## 2. 比特币钱包：BlueWallet

1. 树莓派首页进入 `连接钱包`
2. 选择 `比特币钱包`
3. 选择 `智能卡账户` 或 `已加载助记词`
4. 优先选择 `BlueWallet zpub`
5. 树莓派显示二维码后，用 BlueWallet 导入观察钱包

如果你明确要兼容旧地址，再选择 `BlueWallet xpub`。

## 3. 日常签名

- BTC：手机钱包生成 PSBT，树莓派首页点 `扫码签名`
- Web3：OKX / Bitget / MetaMask / Rabby / TokenPocket 显示签名请求，树莓派首页点 `扫码签名`
- 签完后，手机钱包直接扫树莓派结果二维码
