# 版本时间线与发布入口

这页只回答 3 个问题：

- 现在 GitHub Releases 里哪几个入口代表“当前仓库基线”
- 哪些 release 只是历史公开稳定入口
- 固件 / APK 二进制到底对应哪份源码或哪次构建

如果以后要重建正式发布版，先看：

- [固定正式发布重建入口](固定正式发布重建入口.zh-CN.md)
- [官方程序下载验真与校验](官方程序下载验真与校验.zh-CN.md)

## 1. 先把 3 类入口分开记

### 当前仓库基线 release

- `current-head-clean`
  - 对应当前仓库保留的正式固件资产
  - 资产：
    `system-update-latest.img.xz`
  - 对应当前仓库里保留的 `dist/system-update-latest.*`
- `current-head-wallet-release`
  - 对应当前仓库保留的正式钱包资产
  - 资产：
    `satochip-wallet-release.apk`
  - 对应当前仓库里保留的 `dist/satochip-wallet-release.*`

### 当前正式重建入口

- `firmware-clean -> HEAD`
- `wallet-release -> HEAD`

这表示：

- 以后要按当前源码重建正式基线，不再回到某个旧钱包 / 旧固件 tag
- 真正重建时优先用：
  [固定正式发布重建入口](固定正式发布重建入口.zh-CN.md)

### 历史公开稳定入口

- `offline-signer-firmware-20260410b-clean`
- `wallet-android-20260408-0.1.4`
- `smartcard-app-android-20260330`

这些仍然有参考和下载价值，但不再等于当前 `HEAD`。

## 4. 当前仓库基线和源码怎么对应

- 当前仓库保留的固件基线包：
  `system-update-latest.img.xz`
- 当前仓库保留的钱包基线包：
  `satochip-wallet-release.apk`
- 这两份当前仓库基线产物现在对应的源码提交：
  `979f58d3ad5cecdfec319e14681cde006c7073ab`
- 说明：
  这表示仓库里当前保留的 `dist/` 基线产物是这次构建留下来的，不等于“当前 `HEAD` 已重新编过”

如果你要按当前源码继续重建新的正式基线，改用：

- `bash scripts/rebuild_official_release.sh firmware-clean`
- `bash scripts/rebuild_official_release.sh wallet-release`

详细字段看：

- [固件与源码对应关系](固件与源码对应关系.zh-CN.md)

## 6. 下次该怎么选

### 想直接使用

- 如果你要的是当前仓库保留基线，先看：
  `current-head-clean`
  `current-head-wallet-release`
- 如果你要的是之前已经公开发布过的稳定固件，再看：
  `offline-signer-firmware-20260410b-clean`
- 再看：
  [离线签名器一页备忘](离线签名器一页备忘.zh-CN.md)
- 真机操作再看：
  [离线签名器使用教程](离线签名器使用教程.zh-CN.md)

### 想做复现或长期基线保存

- 先确认你要的是：
  当前仓库基线 release
  还是历史公开稳定 release
- 再看它对应的 `build-info` 或源码冻结 tag
- 最后只跑：
  [固定正式发布重建入口](固定正式发布重建入口.zh-CN.md)

### 想继续开发新功能

- 看：
  `main`
- 但不要把 `main` 直接当成当前仓库基线产物或历史公开稳定固件的精确来源

## 7. 以后看到这些名字时怎么理解

- `current-head-clean`
  当前仓库保留的正式固件基线 release
- `current-head-wallet-release`
  当前仓库保留的正式钱包基线 release
- `offline-signer-firmware-*`
  历史或公开命名的树莓派离线签名器固件 release
- `offline-signer-clean-source-*`
  当前 clean 正式固件的精确冻结源码 tag
- `smartcard-app-android-*`
  安卓“智能卡”App release
- `wallet-android-*`
  历史或公开命名的安卓观察钱包 release

如果以后又出了新固件，最稳的做法还是：

1. 先看 GitHub Releases
2. 再看这页确认它属于“当前仓库基线”还是“历史公开稳定”
3. 最后去看对应 `build-info` / 源码 tag，而不是直接猜 `main`
