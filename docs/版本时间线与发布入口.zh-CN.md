## 2. 树莓派固件和源码怎么对应

- 代表包：
  `system-update-latest.img.xz`
- 适合：
  你现在日常真机使用，也是以后复现和验包的首选基线
- 特点：
  功能已收口到当前正式版，`build-info` 为 clean 新格式
- 注意：
  精确源码看 `offline-signer-clean-source-20260403`

- `offline-signer-firmware-20260403-clean`
  - 固件 release tag
  - 对应当前 clean 正式包
  - 精确源码看：
    `offline-signer-clean-source-20260403`

详细字段看：

- [固件与源码对应关系](固件与源码对应关系.zh-CN.md)

仓库和 GitHub Releases 里的旧 firmware 包已经移除，避免拿错。
当前额外保留的 `BIP85` 预览包，只是为了让新功能可以直接下载试用，不会替换正式 clean 包。

## 3. 下次该怎么选

### 想直接使用

- 先下 GitHub Releases 里当前推荐那张固件
- 再看：
  [离线签名器一页备忘](离线签名器一页备忘.zh-CN.md)
- 真机操作再看：
  [离线签名器使用教程](离线签名器使用教程.zh-CN.md)

### 想做复现或长期基线保存

- 先看当前推荐 clean 正式固件 release
- 再看它对应的源码冻结 tag
- 最后只跑：
  [固定正式发布重建入口](固定正式发布重建入口.zh-CN.md)

### 想继续开发新功能

- 看：
  `main`
- 但不要把 `main` 直接当成正式固件的精确来源

## 4. 以后看到这些名字时怎么理解

- `offline-signer-firmware-*`
  树莓派离线签名器固件 release
- `offline-signer-clean-source-*`
  当前 clean 正式固件的精确冻结源码 tag
- `smartcard-app-android-*`
  安卓“智能卡”App release
- `wallet-android-*`
  安卓观察钱包 release
- `j3r180-card-firmware-*`
  智能卡固件 release

如果以后又出了新固件，最稳的做法还是：

1. 先看 GitHub Releases
2. 再看这页确认对应源码 tag
3. 最后去看对应源码 tag，而不是直接猜 `main`
