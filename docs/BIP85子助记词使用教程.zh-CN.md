# BIP85子助记词使用教程

这份教程只讲一件事：怎么把一条主助记词稳定地派生出很多条子助记词，并把它们管理好、备份好、恢复好。

如果你还没搞清 `BIP85` 和“二次加密假助记词”的区别，先记一句：

- `BIP85` 子助记词是标准 `BIP39` 子钱包
- 二次加密假助记词是为了额外隐藏真助记词而做的中间结果

## 1. `BIP85` 适合拿来干什么

最适合的用法是：

- 用 1 条主父助记词，派生很多条用途不同的子助记词
- 给不同钱包、不同账户、不同设备分开用不同 `index`
- 让每条子助记词彼此独立，但又都能从同一个父助记词重新推出来

长期最稳的思路不是“子助记词再生子助记词再生子助记词”，而是：

- 固定 1 条主父助记词
- 主要靠不同 `index` 管理不同子钱包

## 2. 使用前先准备好什么

开始前至少确认这 4 件事：

1. 你已经把一条标准 `BIP39` 助记词加载进树莓派
2. 你知道这条主父助记词是谁，可以靠指纹或自己的标签认出来
3. 你准备好记录：
   - 子助记词词数
   - `BIP85 index`
   - 用途
4. 你知道子助记词以后是要：
   - 直接完成并留在树莓派
   - 写入 `Satochip`
   - 写入 `SeedKeeper`
   - 再做钛板或钢板备份

## 3. 设备里怎么走这条流程

路径：

- `助记词工具 -> 已加载助记词 -> BIP-85 子助记词`

现在设备里这条线会按下面顺序走：

1. 选择词数：
   - `12 Words`
   - `18 Words`
   - `24 Words`
2. 输入 `BIP85 index`
3. 进入子助记词查看页
4. 可以继续：
   - `查看 BIP39 序号`
   - `验证备份`
   - `完成子助记词`
   - `子助记词写入智能卡`
   - `子助记词写入 SeedKeeper`

当前 `index` 合法范围是：

- `0` 到 `2^31 - 1`

## 4. 正确的操作顺序

建议每次都按这个顺序来：

1. 先加载主父助记词
2. 进入 `BIP-85 子助记词`
3. 选定词数
4. 输入一个还没用过的 `index`
5. 先看 `查看 BIP39 序号`
6. 再做一次 `验证备份`
7. 最后才决定这条子助记词要不要正式保存

这样做的好处是：

- 先把显示结果核对清楚
- 再验证自己有没有真的抄对
- 最后才落到卡或长期备份里

## 5. `完成子助记词` 和直接写卡怎么选

### `完成子助记词`

适合：

- 你想把这条子助记词正式加入当前树莓派的已加载列表
- 你接下来还想继续做：
  - `查看 BIP39 序号`
  - `派生路径算地址`
  - `写入当前助记词到 SeedKeeper`
  - `转成钢板打孔数字`

### `子助记词写入智能卡`

适合：

- 你已经决定把这条子助记词直接变成签名卡
- 你不想再手动回到“已加载助记词”里找它再写一次

### `子助记词写入 SeedKeeper`

适合：

- 你想把这条标准 `BIP39` 子助记词留在 `SeedKeeper`
- 以后希望可以靠卡内标签和指纹识别出它是谁

## 6. 你必须自己记下来的东西

只记“子助记词本体”还不够。至少要额外记下：

- 这条子助记词来自哪条主父助记词
- 主父助记词的指纹或你自己的唯一标签
- 子助记词词数
- `BIP85 index`
- 这条子助记词当前被保存到了哪里

最小记录模板可以这样记：

```text
父助记词指纹：xxxxxxx
子助记词词数：12
BIP85 index：7
用途：主手机观察钱包
额外备份：SeedKeeper / 钛板 / 无
```

如果你丢了下面任意一项，恢复都会变麻烦：

- 父助记词
- `index`
- 词数

## 7. 什么时候要给子助记词做独立备份

如果这条子助记词以后要单独放钱、单独长期使用，那就把它当成一条独立钱包处理。

也就是说，你最好额外做一份：

- `SeedKeeper` 备份
- 钛板直备份
- 或你认可的别的离线备份

不要只想着：

- “反正有父助记词以后再推出来就行”

技术上可以，但实际管理时，缺少 `index` 记录会很容易让你自己把自己绕晕。

## 8. 和钛板/钢板流程怎么配合

如果你要把这条子助记词继续做金属备份，有两种路线：

### 路线 A：标准 `BIP39` 直备份

适合：

- 你希望以后直接靠金属板就能恢复出这条子助记词
- 你不想再多走一层“假助记词 -> 二次还原”

直接看：

- [钛板打孔备份助记词教程](钛板打孔备份助记词教程.zh-CN.md)

### 路线 B：先做二次加密，再转钢板数字

适合：

- 你不想让金属板直接暴露真实子助记词
- 你愿意接受恢复时多一步“二次还原”

当前设备里可以走：

- `二次加密助记词`
- `转成钢板打孔数字`
- `从钢板数字恢复二次助记词`
- `二次还原助记词`

## 9. 推荐的长期管理方式

比较稳的做法是：

1. 固定 1 条主父助记词
2. 按用途分配固定 `index`
3. 每个 `index` 只对应 1 条明确用途的子助记词
4. 真要长期存钱的子助记词，再做独立备份

一个简单例子：

```text
index 0：主手机钱包
index 1：备用手机钱包
index 10：BTC 单独账户
index 100：测试用途
```

这样以后排错、恢复、换设备，都比“临时想到哪个 index 就随手乱用”稳得多。

## 10. 常见错误

### 10.1 忘了记 `index`

这是最常见也最致命的管理错误之一。

### 10.2 把子助记词和假助记词混成一类

它们的用途完全不同，恢复链路也完全不同。

### 10.3 只记了“这是第几个钱包”，没记父助记词是谁

如果你将来不止 1 条父助记词，这样会非常危险。

### 10.4 还没验证备份就正式入金

最少先完成：

- `查看 BIP39 序号`
- `验证备份`
- 一次真实恢复演练

## 11. 最后建议

如果你只是想稳定管理很多钱包，`BIP85` 很值得用；但真正决定你以后会不会出事的，不是能不能派生出来，而是你有没有把这 3 件事记清楚：

- 父助记词是谁
- `index` 是多少
- 这条子助记词最终保存到了哪里
