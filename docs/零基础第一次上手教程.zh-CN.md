# 零基础第一次上手教程

这份教程是写给完全没接触过加密货币、也没接触过这个项目的人看的。

目标只有一个：

- 你第一次看到这些设备、这些名词、这些二维码，也能知道自己现在该做什么

如果以后你把别的教程都忘了，先回来看这份。

如果你已经准备开始实际测试，继续看：

- [第一次小额测试完整流程](第一次小额测试完整流程.zh-CN.md)

## 1. 先用大白话理解这套东西

这个项目不是“一个软件”，而是一整套分工明确的工具。

最简单的理解方式是：

- 手机负责“看余额、填转账内容、显示二维码、最后点广播”
- 树莓派负责“离线看清内容、离线签名”
- 智能卡负责“保管助记词/私钥材料、出签名”

也就是：

- 手机不碰真正的助记词和私钥
- 树莓派尽量不上网
- 智能卡尽量不离手

## 2. 完全小白先记住这 10 个词

### 助记词

就是那串 `12 / 24` 个英文单词。

它相当于：

- 你的总钥匙

谁拿到它，通常谁就能控制你的资产。

### 私钥

它是真正决定能不能花钱的私钥数据。

这套方案的目标就是：

- 尽量不让手机直接保存私钥

### 观察钱包

就是：

- 手机能看余额
- 手机能准备交易
- 但手机自己不能单独花钱

### 冷签

就是：

1. 手机上准备交易
2. 树莓派离线看内容
3. 智能卡签名
4. 手机再把结果发出去

### 广播

就是把已经签好名的交易发到区块链网络。

### 智能卡

就是这套方案里装助记词/私钥材料和做签名的小卡。

### `Satochip`

偏向“签名卡”。

更常做的是：

- 导出地址
- 导出 `BTC xpub / zpub`
- 按路径签名

### `SeedKeeper`

偏向“助记词保管卡”。

更常做的是：

- 保存助记词
- 保存二次加密后的假助记词
- 从卡里再加载回树莓派

### `BlueWallet`

外部的比特币钱包。

它不在这个仓库里。

### `TokenPocket`

外部的以太坊类钱包。

它也不在这个仓库里。

## 3. 先别做这 8 件事

1. 不要把助记词拍照放手机相册。
2. 不要把助记词发给别人。
3. 不要把助记词粘到聊天软件。
4. 不要把真资金主力卡反复恢复出厂。
5. 不要把 `SeedKeeper` 和 `Satochip` 当成一回事。
6. 不要一上来就改高级功能，先走最短主流程。
7. 不要让手机直接保存真正私钥。
8. 不要靠记忆瞎点，照教程一步一步来。

## 4. 你现在属于哪一种情况

你先只需要回答自己一个问题：

- 我现在最想做的到底是哪一件事

最常见就是这 6 种：

1. 我只想把树莓派刷好，先正常开机
2. 我想创建或导入助记词
3. 我想把助记词写进智能卡
4. 我想让树莓派给自己的手机钱包签名
5. 我想让树莓派给 `BlueWallet` 签比特币交易
6. 我想给 `TokenPocket` 做智能卡签名

下面你只看对应那一节就行。

## 5. 第一件事：把树莓派刷好并正常开机

### 5.1 你需要什么

- 一张 `TF` 卡
- 一台读卡的电脑
- 树莓派设备

### 5.2 你需要哪个文件

当前正式固件是：

- `dist/system-update-latest.img.xz`

对应校验文件：

- `dist/system-update-latest.img.xz.sha256`

### 5.3 怎么刷进去

在电脑里：

```bash
cd dist
sha256sum -c system-update-latest.img.xz.sha256
xzcat system-update-latest.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

注意：

- `/dev/sdX` 一定要换成真实的 `TF` 卡设备
- 写错设备会覆盖别的磁盘

### 5.4 第一次开机会看到什么

第一屏先看到：

- `设备登录`

第一次会要求你设置：

- `4-12` 位数字登录密码

设置完后，真正首页标题是：

- `离线签名器`

首页固定 4 个入口：

- `扫码签名`
- `助记词工具`
- `固件完整性自检`
- `智能卡工具`

如果你只想确认机器已经正常：

1. 能开机
2. 能设置登录密码
3. 能再次输入密码进入首页
4. 能看到这 4 个入口

那就算刷机成功了。

## 6. 第二件事：创建或导入助记词

### 6.1 如果你完全没有助记词

最适合新手的方式是：

- `助记词工具 -> 智能卡真随机创建助记词`

这条线最简单，因为：

- 不用你自己造随机数
- 不用掷骰子
- 不用洗牌

做完后你要立刻做两件事：

1. 抄下助记词
2. 抄下 `查看 BIP39 序号` 里的编号

为什么要连编号一起抄：

- 以后核对更稳
- 少一个拼写错误风险

### 6.2 如果你已经有助记词

走：

- `助记词工具 -> 导入助记词`

如果你手里保存的不是英文单词，而是数字编号，就走：

- `助记词工具 -> 按编号导入 BIP39 助记词`

### 6.3 如果你想自己掌控随机数

这时才看这些：

- `摇骰子创建助记词`
- `使用扑克牌创建助记词`
- `使用16进制创建助记词`

对完全新手来说，推荐顺序是：

1. `16进制`
2. `骰子`
3. `扑克牌`

因为：

- `16进制` 最容易核对
- `骰子` 最容易解释
- `扑克牌` 最容易输错格式

## 7. 第三件事：把助记词写进智能卡

### 7.1 先理解两种卡的区别

`Satochip`

- 更像签名卡
- 更适合日常签名

`SeedKeeper`

- 更像助记词保管卡
- 更适合保存助记词或假助记词

### 7.2 最稳的长期方案

准备两张卡：

- 一张专门做 `Satochip`
- 一张专门做 `SeedKeeper`

也就是：

- 一张卡只装一个程序

### 7.3 把当前助记词写进 `Satochip`

前提：

- 你已经在树莓派里加载好了助记词

路径：

- `已加载助记词 -> 写入当前助记词到智能卡`

如果要确认是不是 `Satochip` 那条线，也可以从：

- `智能卡工具 -> Satochip 功能`

进去继续看。

### 7.4 把当前助记词写进 `SeedKeeper`

前提也是：

- 你已经在树莓派里加载好了助记词

常见路径：

- `已加载助记词 -> 写入当前助记词到 SeedKeeper`

### 7.5 写完后最好马上做什么

写完后立刻做 3 件事：

1. 记住卡的用途
2. 记住卡的 `PIN`
3. 再验证一次能不能正常读出来

不要等以后再猜：

- 这张卡到底是 `SeedKeeper` 还是 `Satochip`

## 8. 第四件事：让树莓派给自己的安卓钱包签名

这里说的是本仓库里的安卓观察钱包：

- `dist/satochip-wallet-release.apk`

### 8.1 这款钱包不是干什么的

它不是热钱包。

也就是：

- 手机里不存私钥

它负责的是：

- 看余额
- 准备交易
- 显示待签名二维码
- 扫回树莓派结果
- 最后广播

### 8.2 第一次装好后怎么用

打开后你会看到顶部 3 个页签：

- `首页`
- `活动`
- `DApp`

一般新手先只看：

- `首页`

### 8.3 如果你要发 `Arbitrum` 这类链上的交易

最短流程：

1. 在手机钱包首页选择地址
2. 输入转账内容
3. 手机生成待签名二维码
4. 树莓派进入 `扫码签名`
5. 输入智能卡 `PIN`
6. 树莓派显示结果二维码
7. 手机扫回
8. 手机再人工确认广播

### 8.4 如果你要发比特币

先准备：

- 从树莓派或卡里导出 `BTC xpub / zpub`

再在手机里：

1. 导入 `xpub / zpub`
2. 等余额和活动同步出来
3. 准备比特币交易
4. 手机显示 `PSBT` 待签名二维码
5. 树莓派扫码签名
6. 手机扫回结果
7. 手机人工确认广播

### 8.5 如果你看到 `DApp`

你可以把它理解成：

- 外部网站请求的高安全中转页

它不是浏览器。

## 9. 第五件事：让树莓派给 `BlueWallet` 签比特币

### 9.1 先理解这条线在做什么

`BlueWallet` 负责：

- 看比特币余额
- 填交易内容

树莓派负责：

- 离线签名

### 9.2 最短操作流程

1. 在 `BlueWallet` 里发起交易
2. `BlueWallet` 显示待签名二维码
3. 树莓派进入 `扫码签名`
4. 输入智能卡 `PIN`
5. 树莓派显示已签名结果二维码
6. `BlueWallet` 扫回
7. `BlueWallet` 广播

### 9.3 如果扫回后页面很长怎么办

有时 `BlueWallet` 会把已签名交易显示成一大段长字符。

如果按钮被挤到屏幕外：

1. 先复制交易
2. 再去它的广播入口手动广播

所以不要一看到长字符就慌：

- 那通常只是交易内容长，不是签名坏了

## 10. 第六件事：给 `TokenPocket` 做签名

这里用的是安卓“智能卡”App，不是安卓观察钱包。

### 10.1 这款 App 是做什么的

它负责：

- 扫 `TokenPocket` 请求
- 直接贴卡签名
- 或者先转成树莓派更容易扫的静态二维码

### 10.2 最常用的直接签名流程

1. 在 `TokenPocket` 发起签名或交易
2. 打开安卓“智能卡”App
3. 点 `扫码`
4. 扫 `TP` 请求二维码
5. 输入卡 `PIN`
6. 点 `解锁`
7. 核对页面内容
8. 点 `贴卡/插卡签名`
9. 用 `NFC` 贴卡，或者插上 `USB-OTG + ACR39U`
10. 让 `TokenPocket` 扫回结果

### 10.3 如果树莓派更好扫

可以走另一条路：

1. 安卓“智能卡”App 先扫 `TP` 动态码
2. 它生成树莓派静态中转二维码
3. 让树莓派扫这组静态码
4. 树莓派完成签名

适合：

- `TP` 动态码太快
- 树莓派直接扫不稳

## 11. 第七件事：完全离线初始化 `Satochip` 卡

这件事不是在安卓手机上做，而是在离线电脑里做。

### 11.1 这条线适合什么时候用

- 新卡第一次初始化
- 给卡设 `PIN`
- 把已有助记词导入卡
- 离线生成新助记词写入卡

### 11.2 用哪套工具

用：

- `backups/satochip-utils/`

最详细教程是：

- [../backups/satochip-utils/Tails-离线使用教程.zh-CN.md](../backups/satochip-utils/Tails-离线使用教程.zh-CN.md)

### 11.3 最短理解版流程

1. 打开 `Tails`
2. 接读卡器和卡
3. 装离线依赖
4. 启动智能卡服务
5. 打开 `Satochip-Utils`
6. 设置 `PIN`
7. 导入或生成助记词

## 12. 如果你现在只想先安全开始，最推荐的顺序

对完全新手，最稳的顺序是：

1. 先把树莓派刷好
2. 先创建或导入一条助记词
3. 先看 `查看 BIP39 序号`
4. 再写进一张 `Satochip` 卡
5. 再导出 `xpub / zpub` 给手机观察钱包
6. 先做一笔极小额测试
7. 成功后再考虑 `BIP85`、钢板数字、二次加密这些高级功能

不要一上来就同时做：

- 多张卡
- 多个钱包
- 多种备份路线

那样最容易把自己绕晕。

## 13. 新手最常见的 12 个问题

### 13.1 为什么手机上不能直接转账成功

因为这套设计本来就是：

- 手机准备
- 树莓派离线签名
- 手机最后广播

### 13.2 为什么还要再输入一次 `PIN`

因为真正签名的是智能卡，不是手机。

### 13.3 为什么要把助记词和编号一起记

因为以后核对更稳，少拼写错误。

### 13.4 为什么说 `SeedKeeper` 和 `Satochip` 不是一回事

因为它们用途不同：

- 一个偏保管助记词和备份
- 一个偏做签名

### 13.5 为什么不建议一张卡长期混装两个程序

因为后面容易搞不清用途，也更怕误操作。

### 13.6 为什么手机钱包里看得到余额却不能直接签

因为那只是观察钱包。

### 13.7 为什么要做小额测试

因为第一次最容易是“流程没走熟”，不是“功能真的坏了”。

### 13.8 为什么树莓派要尽量离线

因为它是拿来看清内容、做签名的核心设备。

### 13.9 为什么不建议把助记词拍照

因为手机最容易泄露。

### 13.10 如果以后全部忘了怎么办

先回来重看这份教程，再看：

- [全功能操作总手册](全功能操作总手册.zh-CN.md)

### 13.11 如果我现在只会一条最简单的主线，先学哪条

推荐：

1. 树莓派刷机
2. 创建或导入助记词
3. 写入 `Satochip`
4. 用自己的安卓观察钱包做一笔小额测试

### 13.12 什么东西最绝对不能丢

最重要的是：

- 助记词
- 卡的用途区分
- 卡的 `PIN`
