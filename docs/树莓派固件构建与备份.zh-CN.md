# 树莓派固件构建与备份

这份文档只讲一件事：

- 怎么从当前仓库重新编出可用的树莓派固件
- 怎么把当前可用固件稳定备份到仓库和 GitHub

如果以后只改树莓派固件，优先先看这篇。

## 1. 当前已经验证可用的关键输入

当前可用固件不是只靠 `seedsigner-os` 上游源码就能重现。

真正必须固定的是：

- `seedsigner-os/opt/rootfs-overlay/opt/`
- `seedsigner-os/opt/external-packages/nfc-bindings/nfc-bindings.mk`

其中当前已经验证可用的运行时快照时间是：

```text
seedsigner-os/opt/rootfs-overlay/opt/src/.build_commit_time = 2026-03-10 16:30
```

如果以后这个目录丢了、被 `.gitignore` 忽略了，或者又回到“构建时临时拉外部 `dev` 分支”的方式，就很容易出现：

- 能编过
- 但镜像和原来不一样
- 屏幕不亮
- 键位不对

## 2. 以后只用这一条命令

标准命令：

```bash
bash scripts/build_pi_firmware_from_snapshot.sh
```

这个脚本会按顺序做完：

1. 调用 `scripts/run_seedsigner_build.sh`
2. 用当前仓库里已经冻结的 `rootfs-overlay/opt` 快照构建
3. 生成原始镜像：
   `seedsigner-os/images/seedsigner_os.dev_.pi0-smartcard.img`
4. 自动压缩并覆盖仓库里的稳定备份：
   `dist/system-update-latest.img.xz`
5. 自动更新：
   - `dist/system-update-latest.img.xz.sha256`
   - `dist/system-update-latest.build-info.txt`

## 3. 这套脚本为什么更稳

`scripts/run_seedsigner_build.sh` 已经固定为：

- `--skip-repo`
- `--no-clean`
- `BR2_JLEVEL=4`
- `taskset -c 0,1,2,3`
- `nice 19`
- `ionice -c3`

这样做的目的有两个：

1. 不再从外部仓库临时拉最新代码，避免“今天能编、明天不一样”。
2. 不再像之前那样一上来把整台电脑顶满，降低卡死概率。

如果你确实要改并发，可以自己设环境变量：

```bash
BR2_JLEVEL=3 TP_BUILD_CPUSET=0,1,2 bash scripts/build_pi_firmware_from_snapshot.sh
```

## 4. 当前产物位置

构建完成后，重点看这几个文件：

- 原始镜像：
  `seedsigner-os/images/seedsigner_os.dev_.pi0-smartcard.img`
- 仓库稳定备份：
  `dist/system-update-latest.img.xz`
- 压缩镜像校验：
  `dist/system-update-latest.img.xz.sha256`
- 构建信息：
  `dist/system-update-latest.build-info.txt`

`build-info` 里会记录：

- 运行时快照时间
- 原始镜像 `sha256`
- 压缩镜像 `sha256`
- 用的脚本名
- 打包时间

## 5. 看进度怎么做

构建日志：

```bash
tail -f logs/seedsigner-build-live.log
```

如果想看系统整体情况：

```bash
watch -n 1 'uptime; echo; free -h; echo; pgrep -af "build.sh --pi0 --smartcard --skip-repo --no-clean|linux-custom|post-image-tpminimal|zImage"'
```

## 6. 推 GitHub 前的最短顺序

每次树莓派固件改完后，照这个顺序走：

1. 跑：
   `bash scripts/build_pi_firmware_from_snapshot.sh`
2. 确认：
   - 镜像能亮屏
   - 关键按键没问题
3. 检查：
   `git status`
4. 至少把下面这些一起提交：
   - `seedsigner-os/opt/rootfs-overlay/opt/`
   - `seedsigner-os/opt/external-packages/nfc-bindings/nfc-bindings.mk`
   - 文档
   - `dist/system-update-latest.img.xz`
   - `dist/system-update-latest.img.xz.sha256`
   - `dist/system-update-latest.build-info.txt`
5. 最后再推 GitHub。

## 7. 以后最容易犯错的地方

不要再走这几条旧路：

- 不要直接裸跑 `seedsigner-os/opt/build.sh`
  原因：默认会去拉外部仓库的 `dev`
- 不要再让 `rootfs-overlay/opt` 被忽略
  原因：它就是当前真正可用固件的运行时输入
- 不要只留 `output/` 里的临时镜像
  原因：`output/` 是构建缓存，不是长期备份
- 不要只改代码不更新 `dist` 和 `sha256`
  原因：以后回看时根本不知道哪张是验证通过的

## 8. 当前验证通过的这版

当前这版是按上面流程构建并且设备实机验证过的版本。

如果以后要追溯，先看：

- `dist/system-update-latest.build-info.txt`
- `seedsigner-os/opt/rootfs-overlay/opt/src/.build_commit_time`

这两个文件就是以后继续维护时最重要的入口。
