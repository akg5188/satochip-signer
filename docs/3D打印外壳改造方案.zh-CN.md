# 3D 打印外壳改造方案

这份文档是给当前这套硬件做外壳用的。

你的实物方案大致是：

- `Pi Zero`
- `Waveshare 1.3 寸 240x240` 显示按键板
- `OV5647 legacy camera`
- 顶部外接一个白色读卡器
- 旁边还有一个黑色转接头

## 推荐路线

不要一开始就从零画整壳。

最稳的做法是分两步：

1. 先直接打印现成主壳 `Open Pill`
2. 再额外打印一个“读卡器托盘”固定到主壳顶部

这样做的好处：

- 主机部分已经有成熟文件
- 白色读卡器如果后面换型号，只用重打托盘
- 不需要一开始就改整套外壳
- 试错成本低

## 仓库里的主壳说明

为了避免和正式固件发布件混淆，仓库 `dist/` 里已经不再附带历史外壳压缩包。

所以这份文档只保留结构和尺寸建议，不再把外壳文件当成正式发布件的一部分。

仓库内打印说明已经确认过，`Open Pill` 最省事：

- 单件打印
- 不需要额外螺丝
- 适合 `Pi Zero + Waveshare 240x240 + legacy camera`

根据当前 `open_pill.stl` 的网格包围盒，整壳外部大约是：

- 长：`79.5 mm`
- 宽：`34.5 mm`
- 高：`26.0 mm`

这个尺寸只是外壳整体外形参考，不是内部精确安装尺寸。

## 最推荐的成品结构

### 方案 A：主壳 + 顶部独立托盘

结构：

- 下半部分继续用 `Open Pill`
- 顶部加一个单独的小托盘装白色读卡器
- 托盘底部用 `3M VHB` 双面胶固定到主壳顶部
- 读卡器本体用魔术贴带或扎带固定在托盘里

优点：

- 最容易成功
- 不需要精确吃透主壳全部曲面
- 后期改读卡器尺寸很方便

缺点：

- 外观是一体感稍弱

### 方案 B：一体式改壳

结构：

- 直接改 `open_pill.f3d`
- 在顶部建一个读卡器仓
- 一次打印成一个壳

优点：

- 外观更完整

缺点：

- 改动大
- 一旦尺寸错一点，整壳都要重打

如果你是第一次做，先走方案 A。

## 你现在最该量的尺寸

拿卡尺量下面这些就够了：

### 主机部分

- 主板总长
- 主板总宽
- 主板最高点总高度
- 屏幕外框长宽
- 屏幕玻璃到壳前面的间距
- 摇杆最高点高度
- 三个按键最高点高度
- 摄像头模组厚度
- 摄像头排线弯折所需空间

### 白色读卡器

- 读卡器本体长
- 读卡器本体宽
- 读卡器本体厚
- 卡插入后向上露出的高度
- 读卡器底部接口到机身边缘的距离

### 顶部走线

- 黑色转接头插上后的总宽
- 白色读卡器连接线直径
- 线弯折后需要的最小空间

## 建模留量建议

FDM 打印不要按实物死贴。

建议留量：

- 左右宽度留量：`0.3 - 0.5 mm`
- 前后长度留量：`0.3 - 0.5 mm`
- 高度留量：`0.8 - 1.2 mm`
- 插口开孔放大：`0.5 mm`
- 卡扣缝隙：`0.25 - 0.35 mm`

如果你打印机精度一般，宁可松一点，不要太紧。

## 最实用的托盘结构

建议把顶部读卡器托盘做成下面这种：

- 一个平底底板
- 两侧低侧墙
- 后侧一个挡块
- 底部中间开线槽
- 两个绑带孔

这样白色读卡器放进去以后：

- 下面的线可以从线槽下去
- 上面的卡还能正常插拔
- 读卡器本体不用做得太死
- 就算读卡器外形不是完全规则，也能固定住

## 托盘设计建议尺寸

托盘不是按你的读卡器死值写，而是按参数写。

假设量到白色读卡器本体尺寸为：

- 长 = `reader_len`
- 宽 = `reader_w`
- 厚 = `reader_h`

那么托盘可先按下面经验值设：

- 内腔宽 = `reader_w + 0.8`
- 内腔长 = `reader_len + 0.8`
- 内腔深 = `reader_h * 0.55`
- 底板厚 = `2.4`
- 侧墙厚 = `2.0`
- 侧墙高 = `reader_h * 0.65`
- 挡块厚 = `2.0`
- 绑带槽宽 = `4.0`
- 绑带槽长 = `12.0`
- 线槽宽 = `8.0`
- 线槽长 = `12.0`

## 打印建议

### 主壳

- 材料：`PLA`
- 层高：`0.2 mm`
- 填充：`20% - 30%`
- 壁数：`3`

### 读卡器托盘

- 材料：`PETG` 更好
- 层高：`0.2 mm`
- 填充：`30% - 40%`
- 壁数：`4`

原因：

- 主壳用 `PLA` 就够
- 托盘会反复装拆，`PETG` 比较耐一点

## 打印顺序

不要一次全打。

推荐顺序：

1. 先打印 `open_pill.stl`
2. 装上主机，确认屏幕、按键、摄像头没问题
3. 再打印一个最简托盘试尺寸
4. 托盘合适后再打正式版本

## 最省事的装配方式

### 主壳

- 直接用 `Open Pill`

### 读卡器托盘

- 托盘底部贴 `3M VHB`
- 读卡器用魔术贴带或细扎带固定

如果你不想用胶，也可以后续在托盘底板上加两个小孔，再自己定螺丝方案。

## 建模软件建议

如果你想最好改：

- `Fusion 360`
- `FreeCAD`

如果你想最快改参数：

- `OpenSCAD`

仓库里我已经放了一个参数化托盘草模：

- `case-mod/card_reader_tray_template.scad`

你只要把里面的尺寸参数改成你实测值，再导出 STL 就行。

## 从零开始的最短流程

1. 打印 `Open Pill`
2. 量白色读卡器长宽厚
3. 改 `card_reader_tray_template.scad` 顶部几个参数
4. 导出 STL
5. 先打托盘测试件
6. 没问题再打正式件

## 最后建议

如果你只是想先做一个能用的外壳：

- 不要先做一体壳
- 先做 `Open Pill + 顶部独立托盘`

等这个版本跑通后，再考虑一体化、美化、隐藏线材。
