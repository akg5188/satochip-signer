# 快速开始

这页只保留当前项目最短、最实用的启动路径。

## 1. 先拿树莓派正式固件

- `dist/system-update-latest.img.xz`
- `dist/system-update-latest.img.xz.sha256`
- `sha256 = ba3b136ed80a91e7cb7da32abf707aad616dc9f1cb50c2e83e4a05a1739d6f31`

对应源码：

- `offline-signer-clean-source-20260403`

详细映射看：

- [固件与源码对应关系](固件与源码对应关系.zh-CN.md)

## 2. 烧录 TF 卡

```bash
cd dist
sha256sum -c system-update-latest.img.xz.sha256
xzcat system-update-latest.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

把 `/dev/sdX` 换成你的 TF 卡设备。

GitHub 下载入口：

- `offline-signer-firmware-20260403-clean`

## 3. 开机后先认菜单

当前首页标题就是：

- `离线签名器`

首页 4 个入口：

- `扫码签名`
- `助记词工具`
- `固件完整性自检`
- `智能卡工具`

## 4. 三种常见使用方式

### 自己的安卓钱包 `satochip-wallet-release.apk`

1. 手机生成待签名二维码
2. 树莓派进 `扫码签名`
3. 输入智能卡 `PIN`
4. 树莓派显示结果二维码
5. 手机扫回并人工确认广播

### `BlueWallet`

1. `BlueWallet` 显示 `BTC PSBT` 动态码
2. 树莓派进 `扫码签名`
3. 输入智能卡 `PIN`
4. 树莓派回显结果二维码
5. `BlueWallet` 扫回并广播

### `TokenPocket`

1. 安卓手机打开 `app/` 里的“智能卡”App
2. 扫 `TokenPocket` 动态请求
3. 直接贴卡/插卡签名，或者先转成树莓派静态码
4. 返回结果给 `TokenPocket`

## 5. 树莓派二维码页面怎么操作

如果是多张手动切换二维码：

- 右侧上面键或方向右：下一张
- 右侧中间键或方向左：上一张
- 方向上：调亮
- 方向下：调暗
- 其他确认键：退出二维码页
