# 快速开始

这页只保留当前项目最短、最实用的启动路径。

## 1. 先拿树莓派当前固件

如果你现在就在这台电脑上刷机，优先用本机最新测试包：

- `dist/system-update-seedkeeper-suite-test.img.xz`
- `dist/system-update-seedkeeper-suite-test.img.xz.sha256`
- `sha256 = 04421fb74d4225cf3a4685b923cb991d4cb0cb65e9951250f5bb4ae9b4fc420f`

对应源码：

- 当前本机源码提交：
  `a73a62004e1f0a13b77244c605a5c66d0e02cefa`

如果你是从 GitHub Releases 直接下载，当前公开入口仍然看：

- `offline-signer-firmware-20260403-bip85-preview`

详细映射看：

- [固件与源码对应关系](固件与源码对应关系.zh-CN.md)
- [当前测试固件功能与验证范围](当前测试固件功能与验证范围.zh-CN.md)

## 2. 校验并烧录 TF 卡

```bash
cd dist
sha256sum -c system-update-seedkeeper-suite-test.img.xz.sha256
xzcat system-update-seedkeeper-suite-test.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

把 `/dev/sdX` 换成你的 TF 卡设备。

GitHub 公开下载入口：

- `offline-signer-firmware-20260403-bip85-preview`

## 3. 开机后先认菜单

第一次刷机开机后，先看到的是：

- `设备登录`

这里会强制你设置 `4-12` 位数字登录密码；以后每次开机都要先输入它，才会进入真正的主界面。

登录通过后，首页标题就是：

- `离线签名器`

首页 4 个入口：

- `扫码签名`
- `助记词工具`
- `固件完整性自检`
- `智能卡工具`

如果你的卡里已经同时装了 `SatochipApplet` 和 `SeedKeeper`，现在不需要来回重刷，直接在：

- `助记词工具`
- `智能卡工具`

里分别使用对应功能即可。

如果你想直接用卡内真随机创建助记词，先从：

- `助记词工具 -> 智能卡真随机创建助记词`

进去即可。

如果你想管理卡里的 applet 功能，进：

- `智能卡工具 -> Satochip 功能`
- `智能卡工具 -> SeedKeeper 功能`

如果你之前把“二次加密后的假助记词”保存进了 `SeedKeeper`，恢复入口是：

- `智能卡工具 -> SeedKeeper 功能 -> 从 SeedKeeper 加载二次加密助记词`

如果你想先知道“这张最新测试包到底包含什么、哪些已经测过”，先看：

- [当前测试固件功能与验证范围](当前测试固件功能与验证范围.zh-CN.md)

## 4. 三种常见使用方式

### 自己的安卓钱包 `satochip-wallet-release.apk`

1. 手机生成待签名二维码
2. 树莓派进 `扫码签名`
3. 输入智能卡 `PIN`
4. 树莓派显示结果二维码
5. 手机扫回并人工确认广播

### `BlueWallet`

1. `BlueWallet` 显示 `BTC PSBT` 动态码
2. 树莓派进 `扫码签名`
3. 输入智能卡 `PIN`
4. 树莓派回显结果二维码
5. `BlueWallet` 扫回并广播

### `TokenPocket`

1. 安卓手机打开 `app/` 里的“智能卡”App
2. 扫 `TokenPocket` 动态请求
3. 直接贴卡/插卡签名，或者先转成树莓派静态码
4. 返回结果给 `TokenPocket`

## 5. 助记词原始熵怎么核对

在已加载助记词里，现在可以直接看：

- `查看原始熵(HEX)`
- `显示二维码`

手机扫这个二维码拿到的就是原始熵 `HEX`，可以直接贴到 `BIP39` 网站的原始熵输入框做人工复核。
注意不是网站的 `Dice` 模式。

当前助记词或 `BIP85` 子助记词现在也可以直接写入：

- `SatochipApplet`
- `SeedKeeper`

二次加密后的假助记词现在也可以：

- 保存到 `SeedKeeper`
- 从 `SeedKeeper` 加载回树莓派继续二次还原

如果助记词来自 `SeedKeeper` 真随机创建，原始熵 `HEX` 一样可以查看和显示二维码。

## 6. 树莓派二维码页面怎么操作

如果是多张手动切换二维码：

- 右侧上面键或方向右：下一张
- 右侧中间键或方向左：上一张
- 方向上：调亮
- 方向下：调暗
- 其他确认键：退出二维码页
