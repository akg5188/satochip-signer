## 1. 下载哪些文件

安卓：

- TP 签名中转 APK：
  优先从对应 GitHub Release 下载，或本地运行 `bash scripts/build_tp_relay_apk.sh` 生成
- 仓库 `dist/` 默认不长期保留 TP 中转 APK
- 本地生成后对应校验：
  `dist/tp-qr-relay-android-latest.apk.sha256`

树莓派固件：

- 固件镜像：
  `https://raw.githubusercontent.com/akg5188/tp-satochip-signer/main/dist/system-update-latest.img.xz`
- 对应校验：
  `dist/system-update-latest.img.xz.sha256`

如果你要的是独立钱包，而不是给 `TokenPocket` 做签名中转，请改看：

- [两个安卓 APK 说明](两个安卓APK说明.zh-CN.md)

## 2. Ubuntu 下校验固件

```bash
cd /path/to/tp-satochip-signer/dist
sha256sum -c system-update-latest.img.xz.sha256
```

## 3. 烧录到 TF 卡

先确认 TF 卡设备名：

```bash
lsblk
```

烧录：

```bash
xzcat system-update-latest.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

把 `/dev/sdX` 换成你的 TF 卡。

## 4. 装哪个安卓 App

如果你要用的是：

- 你自己的安卓观察钱包：装 `satochip-wallet-release.apk`
- `BlueWallet`：直接用 `BlueWallet`，不需要 TP 中转 App
- `TokenPocket`：从对应 Release 下载或本地现编 `tp-qr-relay-android-latest.apk`

不要混用：

- `BlueWallet` 不走 TP 中转 App
- `satochip-wallet-release.apk` 也不走 TP 中转 App
- 只有 `TokenPocket` 需要中转 App

## 5. 最短实际使用流程

### 5.1 你自己的安卓钱包 `satochip-wallet-release.apk`

1. 手机上生成待签名二维码
2. 树莓派扫二维码
3. 输入智能卡 `PIN`
4. 树莓派显示结果二维码
5. 手机扫回结果并确认广播

### 5.2 BlueWallet

1. `BlueWallet` 显示待签名动画二维码
2. 树莓派用 `扫码签名` 扫描
3. 输入智能卡 `PIN`
4. 树莓派显示回传二维码
5. `BlueWallet` 扫回并广播

### 5.3 TokenPocket

1. 打开 `tp-qr-relay-android-latest.apk`
2. 先让它扫 `TokenPocket` 动态二维码
3. 中转 App 再把二维码给树莓派扫
4. 树莓派输入 `PIN` 并签名
5. 手机扫回结果广播

## 6. 当前适用范围

已支持：

- EVM 转账
- `personalSign`
- `signTypedData`
- `signTypedDataV4`
- `BTC PSBT` 冷签
- `BlueWallet BTC PSBT` 扫码签名

## 7. 常见问题

### 树莓派扫不动 TP 动态二维码

这是 Pi Zero 1 性能限制。当前方案就是用安卓 App 先中转，再给 Pi 扫静态码。

### BlueWallet 扫回结果感觉慢

先试：

1. 在树莓派二维码界面按 `上` 键调亮
2. 手机先离远一点对焦
3. 正对屏幕，至少等完整一轮动画

### 固件怎么确认是不是这版

先看：

- `dist/system-update-latest.img.xz`
- `dist/system-update-latest.build-info.txt`
- `docs/树莓派签名器使用教程.zh-CN.md`

### 输入 PIN 后签名失败

先看屏幕上的错误码或错误文字，再按问题定位。当前镜像已经会显示更具体的失败原因。
