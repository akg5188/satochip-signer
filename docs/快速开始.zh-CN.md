## 1. 先拿当前树莓派固件

当前默认固件产物：

- `dist/system-update-latest.img.xz`
- `dist/system-update-latest.img.xz.sha256`
- 当前工作区测试包名：
  `dist/system-update-worktree-latest.img.xz`

对应入口现在分两种：

- 当前 clean 固件：
  `bash scripts/rebuild_official_release.sh firmware-clean`
- 当前工作区最新：
  `bash scripts/build_current_firmware.sh`
- 历史公开 `20260410b` 固件：
  `bash scripts/rebuild_official_release.sh firmware-public-20260410b-clean`

补一句最重要的区别：

- `firmware-clean` 只认当前 `HEAD`；如果你还有未提交的新功能，它会直接拒绝，防止误编到旧内容
- `build_current_firmware.sh` 才会把你当前工作区里还没提交的最新改动一起打进包，默认产物是 `system-update-worktree-latest.*`

## 2. 校验并烧录 TF 卡

```bash
cd dist
sha256sum -c system-update-latest.img.xz.sha256
xzcat system-update-latest.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

把 `/dev/sdX` 换成你的 TF 卡设备。

如果你刷的是当前工作区测试包，就把上面两个文件名改成 `system-update-worktree-latest.img.xz` 对应那组。

GitHub 公开下载入口统一看：

- [版本时间线与发布入口](版本时间线与发布入口.zh-CN.md)

## 3. 开机后先认菜单

第一次刷机开机后，先看到的是：

- `设备登录`

这里会强制你设置 `4-12` 位数字登录密码；以后每次开机都要先输入它，才会进入真正的主界面。

登录通过后，首页标题就是：

- `离线签名器`

首页 4 个入口：

- `扫码签名`
- `助记词工具`
- `智能卡工具`
- `固件自检`

当前更稳的长期方案是：

- `SeedKeeper` 一张专用卡
- `SatochipApplet` 一张专用卡

也就是 `一张卡只装一个程序`。

如果你手里已经有双 applet 共卡，日常查看/导入/签名还可以继续用，但不要在固件里做 `重置 Satochip / 重置 SeedKeeper`。

如果你想直接用卡内真随机创建助记词，先从：

- `助记词工具 -> 创建助记词 -> 智能卡创建`

进去即可。

如果你想自己离线造随机数再生成助记词，现在还有：

- `助记词工具 -> 创建助记词 -> 扑克牌创建`
- `助记词工具 -> 创建助记词 -> 16进制创建`
- `助记词工具 -> 创建助记词 -> 骰子创建`

这 3 条的详细数量、输入格式、网站核验方式，直接看：

- [离线熵创建助记词教程](离线熵创建助记词教程.zh-CN.md)

如果你想管理卡里的 applet 功能，进：

- `智能卡工具 -> Satochip 功能`
- `智能卡工具 -> SeedKeeper 功能`

如果你之前把“二次加密后的假助记词”保存进了 `SeedKeeper`，恢复入口是：

- `智能卡工具 -> SeedKeeper 功能 -> 从 SeedKeeper 加载二次加密助记词`

如果你想看当前正式版发布前已经覆盖过哪些自动化和真机检查，先看：

- [当前测试固件功能与验证范围](当前测试固件功能与验证范围.zh-CN.md)
- [真机全套回归清单](真机全套回归清单.zh-CN.md)

## 4. 三种常见使用方式

### 自己的安卓钱包 `satochip-wallet-release.apk`

1. 手机生成待签名二维码
2. 树莓派进 `扫码签名`
3. 输入智能卡 `PIN`
4. 树莓派先显示签名摘要
5. 确认后点 `显示签名二维码`
6. 手机扫回并人工确认广播

### `BlueWallet`

1. `BlueWallet` 显示 `BTC PSBT` 动态码
2. 树莓派进 `扫码签名`
3. 输入智能卡 `PIN`
4. 树莓派先显示签名摘要
5. 确认后点 `显示签名二维码`
6. `BlueWallet` 扫回并广播

### `TokenPocket`

1. 安卓手机打开 `app/` 里的“智能卡”App
2. 扫 `TokenPocket` 动态请求
3. 直接贴卡/插卡签名，或者先转成树莓派静态码
4. 返回结果给 `TokenPocket`

如果 `TokenPocket` 的签名请求二维码太密，先这样做：

1. 让 `TokenPocket` 保持显示签名二维码并录屏几秒
2. 打开相册播放这段录屏
3. 播放时把二维码适度放大，但不要把四边裁掉
4. 再让安卓“智能卡”App 或树莓派去扫这段录屏

如果是动态二维码，不要截图成单张；要让录屏里的二维码完整循环播放。

### `OKX Wallet / Bitget Wallet`

这条线优先直接走树莓派，不需要安卓中转。

1. 树莓派首页进 `连接钱包 -> Web3钱包`
2. 选择 `OKX钱包` 或 `Bitget钱包`
3. 选择 `智能卡账户` 或 `已加载助记词`
4. 树莓派显示 `Keystone` 兼容连接二维码
5. 在 `OKX Wallet / Bitget Wallet` 里添加 `Keystone` 硬件钱包并扫描
6. 发起转账或 DApp 签名时，树莓派首页点 `扫码签名`
7. 钱包二维码太密时，用安卓 `扫描钱包二维码并中转`
8. 树莓派确认后显示 `eth-signature`
9. `OKX Wallet / Bitget Wallet` 直接扫回并继续广播 / 完成签名

补充：

- `OKX` 多数可以直接扫
- `Bitget` 如果签名请求二维码太密，先录屏，再在相册里把录屏适度放大播放给安卓观察钱包或树莓派扫
- 放大时不要裁掉二维码四角；如果是动态二维码，要让它完整循环播放

连接 `BlueWallet` 这类比特币观察钱包时，走 `连接钱包 -> 比特币钱包`，选择 `智能卡账户` 或 `已加载助记词` 后导出 `zpub/xpub`。

## 5. 助记词原始熵怎么核对

在已加载助记词里，现在可以直接看：

- `查看原始熵`
- `显示二维码`

手机扫这个二维码拿到的就是原始熵 `HEX`，可以直接贴到 `BIP39` 网站的原始熵输入框做人工复核。
注意不是网站的 `Dice` 模式。

当前助记词或 `BIP85` 子助记词现在也可以直接写入：

- `SatochipApplet`
- `SeedKeeper`

二次加密后的假助记词现在也可以：

- 保存到 `SeedKeeper`
- 从 `SeedKeeper` 加载回树莓派继续二次还原

如果助记词来自 `SeedKeeper` 真随机创建，原始熵 `HEX` 一样可以查看和显示二维码。

## 6. 树莓派二维码页面怎么操作

如果是多张手动切换二维码：

- 右侧上面键或方向右：下一张
- 右侧中间键或方向左：上一张
- 方向上：调亮
- 方向下：调暗
- 其他确认键：退出二维码页
