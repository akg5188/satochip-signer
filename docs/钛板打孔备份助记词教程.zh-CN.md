# 钛板打孔备份助记词教程

这份教程把两条经常被混在一起的路线拆开讲：

1. 标准 `BIP39` 助记词直备份到钛板
2. 先做二次加密假助记词，再转成钢板数字/打孔位

默认优先推荐的是第 1 条，因为恢复链路最短、最不容易把自己绕晕。

## 1. 先选你到底要哪条路线

### 路线 A：标准 `BIP39` 直备份到钛板

特点：

- 钛板上记录的就是这条真实助记词对应的打孔位
- 以后只靠钛板就能直接反推出真实助记词
- 最适合长期主备份

适合：

- 主父助记词
- 重要 `BIP85` 子助记词
- 你希望恢复路径尽量短、尽量稳的场景

### 路线 B：二次加密假助记词 -> 钢板数字/打孔位

特点：

- 金属板上记录的不是最终真助记词，而是中间的假助记词结果
- 恢复时必须先恢复假助记词，再继续 `二次还原助记词`
- 更适合“我不想让金属板直接暴露真助记词”的场景

适合：

- 你已经完全理解自己的运算规则
- 你已经演练过“恢复假助记词 -> 二次还原”的完整链路

如果你还不熟，优先走路线 A。

## 2. 路线 A：标准 `BIP39` 直备份到钛板

### 2.1 先准备这些文件

钛板工具都已经在仓库里：

- [钛板工具包总说明](../钛板工具包/钛板工具包总说明.md)
- [钛板工具包_速查版](../钛板工具包/钛板工具包_速查版.md)
- [bip39_打孔还原说明](../钛板工具包/bip39_打孔还原说明.md)
- [bip39_a4_binary_print.pdf](../钛板工具包/bip39_a4_binary_print.pdf)
- [a4_5cm_grid_sheet.pdf](../钛板工具包/a4_5cm_grid_sheet.pdf)
- [bip39_最终检查清单_a4.pdf](../钛板工具包/bip39_最终检查清单_a4.pdf)

正式开工前，建议至少打印：

- `钛板工具包_速查版_a4.pdf`
- `bip39_a4_binary_print.pdf`
- `bip39_最终检查清单_a4.pdf`

### 2.2 在树莓派里先把助记词核对清楚

先把目标助记词加载进固件，然后进入：

- `助记词工具 -> 已加载助记词 -> 查看 BIP39 序号`

现在这就是标准核对页。每一页都会同时给你：

- 词位
- 单词
- `0-2047` 编号

不要再按旧教程找“查看助记词”那套老排版了。

### 2.3 打孔位规则

当前钛板工具包默认使用 11 位二进制位权：

```text
1 2 4 8 16 32 64 128 256 512 1024
```

当前推荐的视觉分组是：

```text
1 2 4 8 16 32 | 64 128 256 512 1024
```

也就是前 6 位一段，后 5 位一段。

### 2.4 实际打孔顺序

建议逐词这样做：

1. 在树莓派里看这一个词的 `BIP39` 序号
2. 在工具包打印表里找到对应序号的 11 位打孔位
3. 先在钛板对应行做浅定位点
4. 再打成最终凹点
5. 打完立刻按 `1 2 4 8 ... 1024` 回算一次
6. 回查结果对应的单词，确认还是原单词

只要任何一词对不上，就先停，不要继续往下打。

### 2.5 打完后必须做什么

正式用于存钱前，至少做 3 轮检查：

1. 遮住原助记词，只靠钛板独立反推一遍
2. 把反推出来的结果重新导入一遍设备或临时环境
3. 再做一次小额或空钱包恢复演练

没有完整演练成功前，不要直接放正式资产。

### 2.6 `BIP39 passphrase` 要单独保存

如果你用的是 `BIP39 passphrase`：

- 它不在钛板里
- 它不在标准助记词单词里
- 也不会自动出现在树莓派“查看 BIP39 序号”页面里

所以它必须单独保存、单独演练恢复。

## 3. 路线 B：二次加密假助记词 -> 钢板数字/打孔位

这条路线不等于标准钛板直备份。它是“先变假，再备份假”。

### 3.1 正确顺序

建议按这个顺序走：

1. 先加载真助记词
2. 进入 `二次加密助记词`
3. 给每个词输入运算方式和数字
4. 得到假助记词后先看：
   - `查看 BIP39 序号`
5. 再决定要不要：
   - `保存二次加密助记词到 SeedKeeper`
   - `转成钢板打孔数字`

### 3.2 当前运算规则

当前固件里，运算符按字面执行：

- `+` 就是加
- `-` 就是减

不要再按旧版本那种“还原方向自动反过来”的思路理解。

### 3.3 `转成钢板打孔数字` 页现在怎么看

现在这页会把每个词拆成：

- 当前词位
- 对应编号
- 前 `6` 位打孔位
- 后 `5` 位打孔位

也就是：

```text
1 2 4 8 16 32
64 128 256 512 1024
```

这页是为了让你更容易把“数字位权”直接做成金属点位，不是标准 `BIP39` 工具包那套“查词表再打”的路线。

### 3.4 恢复时不要少一步

恢复路径必须完整走完：

1. `助记词工具 -> 从钢板数字恢复二次助记词`
2. 进入检查页，必要时用 `编辑当前页` 改错
3. 先恢复出假助记词
4. 再进入 `二次还原助记词`
5. 最后才回到真助记词

只恢复到假助记词就停住，不算完成恢复。

### 3.5 假助记词还可以再留一份卡内备份

如果你不想只靠金属板，也可以同时保存到：

- `智能卡工具 -> SeedKeeper 功能 -> 保存二次加密助记词到 SeedKeeper`

以后就能从：

- `从 SeedKeeper 加载二次加密助记词`

直接读回，再继续二次还原。

## 4. 什么时候选路线 A，什么时候选路线 B

优先这样选：

- 想最稳、最短恢复链路：
  选路线 A
- 想让金属板不直接暴露真助记词：
  选路线 B

如果你准备拿这条备份长期放真资金，而你又不是特别熟，建议先把路线 A 完整跑通，再考虑路线 B。

## 5. 最低验收标准

不管走哪条路线，真正合格前至少都要满足：

1. 你已经完整做过一轮盲恢复
2. 恢复结果与你原始预期逐词一致
3. 如果用了 passphrase，也已经一起验证
4. 你已经做过一次小额或空钱包演练

## 7. 最后建议

如果你只是想要一份长期可靠、以后不容易忘流程的金属备份：

- 标准 `BIP39` 真助记词优先做钛板直备份
- `BIP85` 子助记词如果真要长期用，也把它当独立钱包认真备份
- 二次加密假助记词路线只在你完全理解恢复链时再上正式资产

如果你下一步准备做子助记词，继续看：

- [BIP85子助记词使用教程](BIP85子助记词使用教程.zh-CN.md)
