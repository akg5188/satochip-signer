# 常见故障一问一答

这份文档不是讲原理，而是专门给你在“卡住了、不知道哪里错了”的时候直接查的。

用法很简单：

- 先找最像你现在情况的问题
- 先按这里的顺序排查
- 不要一上来就怀疑所有东西都坏了

如果你是第一次用这套方案，建议先配合看：

- [零基础第一次上手教程](零基础第一次上手教程.zh-CN.md)
- [第一次小额测试完整流程](第一次小额测试完整流程.zh-CN.md)

## 1. 树莓派开不了机或进不了主页

### 问：刷完卡以后，树莓派开机没反应怎么办？

先按这个顺序看：

1. `TF` 卡是不是写到了正确设备
2. 烧录前有没有先校验 `.sha256`
3. 电源是不是稳定
4. 屏幕和按键连接是不是正常

如果你根本不确定镜像是不是那张正式镜像，先回去看：

- [固件下载与写入指南](固件下载与写入指南.zh-CN.md)

### 问：开机只看到 `设备登录`，是不是卡死了？

不是。

这是正常流程。

现在固件就是：

- 先出现 `设备登录`
- 输入登录密码
- 再进入首页 `离线签名器`

### 问：忘了树莓派登录密码怎么办？

这时不要乱猜，也不要反复输。

如果你真的完全忘了，而且又没有别的恢复方式，通常只能重新刷机并重新走初始化流程。

所以登录密码一定要单独记好。

## 2. 树莓派扫不到二维码

### 问：树莓派就是扫不到手机二维码怎么办？

先按顺序试：

1. 手机亮度调高
2. 手机和树莓派距离稍微拉开
3. 保持二维码正对镜头，不要倾斜
4. 不要让手挡住相机
5. 如果是动态码，尽量让手机保持稳定

如果还是不稳：

- `TokenPocket` 路线改走“安卓智能卡 App 先转静态码，再让树莓派扫”
- `BlueWallet` 路线保持动画码连续播放，不要手动频繁切出页面
- `OKX Wallet / Bitget Wallet` 连接码走树莓派 `连接钱包 -> Web3钱包`；签名请求码太密时，再让安卓观察钱包转成树莓派中转码

### 问：树莓派扫到了，但显示内容根本不是我要签的那笔，怎么办？

先停，不要签。

重新确认：

1. 手机当前打开的是不是正确钱包
2. 你是不是点开了旧交易页面
3. 收款地址和金额是不是你刚输入的那一笔

只要有一项不对，就退出重新来。

## 3. 输入 `PIN` 后签名失败

### 问：我明明输入了 `PIN`，为什么还是签不了？

最常见只有这 4 种：

1. `PIN` 输错了
2. 拿错卡了
3. 这张卡不是你以为的那张 `Satochip`
4. 卡状态本身有问题

先别急着重置卡。

先确认：

- 你手上这张卡到底是什么用途
- 你记的 `PIN` 是不是这张卡的

### 问：怎么判断是拿错卡了？

最简单的判断方式：

- 这张卡以前主要拿来做什么
- 你现在进的是 `Satochip 功能` 还是 `SeedKeeper 功能`

如果你连这张卡是什么都不确定，先停下来，不要继续签正式资金。

## 4. 手机扫不回树莓派结果二维码

### 问：树莓派已经签好了，但手机扫不回结果，怎么办？

先按这个顺序试：

1. 把树莓派二维码调亮
2. 手机镜头对准后多停几秒
3. 如果是动画二维码，不要手动翻页
4. 如果是手动页，再用左右键换页

### 问：怎么知道现在是自动动画二维码还是手动翻页二维码？

如果二维码自己在变化：

- 那就是自动动画

这时你不用手动翻页。

如果页面不动：

- 那就是手动翻页页

这时才用左右键。

## 5. `BlueWallet` 相关问题

### 问：`BlueWallet` 能扫回树莓派结果，但页面里是一大段很长的字符，怎么办？

这通常不是签名坏了。

而是：

- `BlueWallet` 自己把已签名交易显示成很长的 `tx hex`

如果底部广播按钮被挤出屏幕：

1. 先复制那段交易内容
2. 再去它的广播入口粘贴广播

### 问：`BlueWallet` 为什么能扫回，但我还是不敢广播？

这是正常的谨慎。

再核对这 3 项：

1. 金额
2. 地址
3. 手续费

都对，再点广播。

### 问：`BlueWallet` 比较长的交易是不是更贵？

真正决定手续费的不是“字符看起来有多长”，而是：

- 交易大小
- 输入数量
- 费率

如果输入更多，通常会更贵。

## 6. 自家安卓观察钱包相关问题

### 问：为什么手机钱包能看余额，但不能自己直接花钱？

因为它是：

- 观察钱包

它的设计就是：

- 手机准备交易
- 树莓派离线签名
- 手机最后广播

### 问：为什么比特币同步有时还是要等？

现在主网已经优先走：

- `Electrum`

比旧方案快很多。

但如果：

- 网络慢
- 后端暂时不可用

就还是会感觉慢一些。

这时先确认：

1. 账户有没有真的导入成功
2. 是不是主网
3. 手机网络是不是正常

### 问：为什么锁屏以后 `DApp` 会断？

这是当前高安全策略的正常行为，不是故障。

## 7. 安卓“智能卡”App 相关问题

### 问：安卓“智能卡”App 扫完码后提示“请先输入 PIN 并贴卡解锁”，怎么办？

按顺序做：

1. 先输入卡 `PIN`
2. 点 `解锁`
3. 再贴卡或插读卡器

### 问：贴卡没反应怎么办？

先确认：

1. 手机 `NFC` 已开启
2. 卡放在正确感应区域
3. 没有别的 App 抢占 `NFC`

### 问：插 `USB-OTG + ACR39U` 没反应怎么办？

先确认：

1. `OTG` 线正常
2. 读卡器已通电
3. 手机已经允许这个 App 访问 USB

### 问：为什么页面里会出现“树莓派静态中转二维码”？

因为这款 App 不只是直接签名工具，它还负责：

- 把 `TokenPocket` 的动态码转成树莓派更容易扫的静态码

## 8. `OKX Wallet / Bitget Wallet` Web3 桥接问题

### 问：Web3 钱包的二维码树莓派扫不到怎么办？

不要让树莓派硬扫高密度码。

正确路线是：

1. 树莓派首页进 `连接钱包 -> Web3钱包`
2. 选择 `OKX钱包` 或 `Bitget钱包`
3. 选择 `智能卡账户` 或 `已加载助记词`
4. Web3 钱包添加 Keystone 硬件钱包并扫描树莓派连接码
5. 签名时用安卓观察钱包 `扫描钱包二维码并中转` 先扫 Web3 钱包二维码
6. 安卓观察钱包会转成树莓派更容易扫的中转二维码
7. 树莓派签完后，直接让原钱包扫描树莓派结果码，不要再扫回手机

### 问：`Bitget / TokenPocket` 的高密度签名二维码还是扫不进去，怎么办？

当前先用这个临时办法：

1. 让钱包保持显示签名二维码，并录屏几秒
2. 打开相册里的这段录屏
3. 播放录屏时双指稍微放大，让二维码尽量铺满屏幕
4. 注意四个角不要被裁掉
5. 把手机亮度调高
6. 再让树莓派或安卓中转 App 去扫这段放大后的录屏

补充：

- 如果二维码本身是动态的，不要截图成单张图
- 要让录屏里的二维码完整循环播放
- 当前实测更换 `120` 度摄像头后，`OKX / MetaMask / Rabby` 大多可以直接扫，`Bitget / TokenPocket` 更容易在高密度签名码上卡住

### 问：这是不是把私钥导进手机了？

不是。

安卓观察钱包只保存公开地址、公钥、链码和 `xpub` 这类观察信息；真正签名仍在树莓派和智能卡那边完成。

## 9. 助记词相关问题

### 问：助记词和 `BIP39` 编号，到底哪个更重要？

都重要。

但当前更稳的核对方式是：

- 助记词和编号一起记

### 问：`查看 BIP39 序号` 和 `查看原始熵` 有什么区别？

`查看 BIP39 序号`

- 看每个单词在官方词表里的编号

`查看原始熵`

- 看这条助记词对应的原始随机熵

### 问：`BIP85` 子助记词和二次加密后的假助记词是不是一回事？

不是。

`BIP85`

- 是标准子钱包路线

二次加密后的假助记词

- 是隐藏真助记词的中间结果

## 10. 智能卡相关问题

### 问：`SeedKeeper` 和 `Satochip` 到底怎么分？

最简单记法：

`Satochip`

- 偏签名

`SeedKeeper`

- 偏助记词和备份保管

### 问：一张卡能不能同时装两个 applet？

技术上可以有某些共存情况，但长期最稳的方案仍然是：

- 一张卡只装一个程序

### 问：什么时候绝对不要点重置？

只要你不完全确定：

- 这张卡的用途
- 卡里还有没有重要助记词或备份数据

就不要点：

- `重置 Satochip`
- `重置 SeedKeeper`
