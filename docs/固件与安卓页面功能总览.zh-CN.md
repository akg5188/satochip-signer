# 固件与安卓页面功能总览

这份文档把当前仓库里 3 套可见界面统一画出来：

- 树莓派固件 `seedsigner-os`
- 安卓钱包 APK `wallet`
- 智能卡中转 APK `app`

目的只有一个：
一眼看清楚“有哪些页面、每个页面做什么、主流程怎么走”。

## 1. 总体结构

```text
项目界面总览
├─ 树莓派固件 seedsigner-os
│  ├─ 标准 SeedSigner 主菜单
│  └─ 离线签名器 TP_ONLY 主菜单
├─ 安卓钱包 APK wallet
│  ├─ 首页
│  ├─ 活动
│  └─ DApp
└─ 智能卡中转 APK app
   ├─ 单页签名台
   └─ 连续扫码页
```

### 4.1 页面结构

```text
智能卡中转 APK
├─ 单页签名台
│  ├─ 中转来源选择
│  │  ├─ TokenPocket
│  │  ├─ OKX
│  │  └─ Bitget
│  ├─ BIP32 路径输入
│  ├─ 卡 PIN 输入 / 解锁
│  ├─ 请求载荷输入区
│  ├─ 扫码
│  ├─ 解析
│  ├─ 贴卡/插卡签名
│  ├─ 请求详情核对
│  ├─ 中转二维码翻页
│  ├─ 签名结果二维码
│  └─ 打开 TP
└─ 连续扫码页
   ├─ 多段二维码接收
   ├─ 状态提示
   └─ 扫完后返回主页面
```

### 4.2 它的定位

这不是完整钱包，而是：

- 手机侧离线中转器
- 扫高密度钱包二维码
- 转成树莓派更容易扫的静态二维码
- 用 NFC 或 USB 读卡器连接 Satochip 完成签名
- 再把结果二维码交回原钱包

## 5. 三套界面的职责分工

```text
树莓派固件
├─ 冷端主脑
├─ 助记词管理
├─ 签名审核
├─ 智能卡工具
└─ 固件自检

安卓钱包 APK
├─ 观察钱包
├─ 资产与活动展示
├─ DApp / WalletConnect
├─ 生成树莓派签名请求
└─ 广播交易

智能卡中转 APK
├─ 手机离线中转
├─ 高密度码转低密度码
├─ Satochip 贴卡签名
└─ 签名结果回传
```
