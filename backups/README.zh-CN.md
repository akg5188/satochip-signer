# backups 说明

这个目录放的是“备份类内容”，不是主工程源码入口。

目前这里主要有两类东西：

- `android-apk/`
  以前备份下来的安卓安装包
- `satochip-utils/`
  `Satochip-Utils` 的离线备份，用来在 `Tails OS` 中给 `J3R180` 卡设置 `PIN` 和助记词
