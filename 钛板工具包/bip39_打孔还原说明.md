打印版当前规则：

- 序号范围：`0-2047`
- 每一行格式：`序号-单词`
- 左到右位序：`1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024`
- 黑点：这一位是 `1`
- 空心点：这一位是 `0`

也就是说，最左边第一个点代表 `1`，第二个点代表 `2`，第三个点代表 `4`，依次翻倍。

## 一、怎么打孔

假设你已经有一组 BIP39 助记词，要把它们转成打孔记录：

1. 按助记词原始顺序处理，绝对不要打乱顺序。
2. 在打印表里找到该单词所在的那一行。
3. 再核对一次左边的数字序号和单词是否完全一致。
4. 看这一行右侧的 11 个点。
5. 哪些位置是黑点，就在你的钛板对应位置打孔。
6. 哪些位置是空心点，就不要打孔。

例子：

- 如果某一行黑点出现在 `1 + 4 + 8` 这三个位置，那么它对应的序号就是 `13`
- 如果某一行 11 个位置全都不打孔，那么序号就是 `0`
- 如果 11 个位置全部打孔，那么序号就是 `2047`

## 二、怎么从打孔还原单词

要从钛板反推出助记词：

1. 按词的位置顺序，一行一行读取，不要跳位。
2. 从左到右看 11 个位置，分别对应：

`1 2 4 8 16 32 64 128 256 512 1024`

3. 哪个位置被打孔，就把对应数字加起来。
4. 最后得到一个 `0-2047` 的总和。
5. 用这个总和回到打印表里查找对应的 `序号-单词`。
6. 抄下那个单词。

例子：

- 打孔位置是 `1 + 4 + 8`
- 总和就是 `13`
- 在表里找到 `13-accuse`
- 这个词就是 `accuse`

## 三、最重要的复核流程

这一步一定要做，不要省。

每打完一个单词，立刻做一次单词级复核：

1. 看打印表，确认你是照着正确的单词行打的。
2. 再把刚打好的孔按 `1,2,4,8...` 重新加一遍。
3. 算出序号后，再回打印表查一次。
4. 确认查回来的单词，和原始单词完全一样。

整套全部打完后，再做一次全量复核：

1. 把原始助记词先遮住，不要看。
2. 只看钛板，从第一词到最后一词完整反推一遍。
3. 反推出的整组助记词，必须和原始助记词逐词逐位置完全一致。
4. 只要有任何一个词不一致，就不要投入使用，先查错重做。

## 四、容易出错的地方

- 词序错：BIP39 助记词顺序非常重要，词对了但顺序错了也会失败。
- 看错行：一定要同时核对“序号”和“单词”，不要只看单词大概像。
- 少打一孔或多打一孔：只差一位，得到的就是另一个合法单词。
- 把位序看反：本目录当前版本固定是左到右 `1,2,4,8...1024`。
- 只做一次检查：必须做“打完即复核”加“整套盲还原复核”两轮。

## 五、强提醒

- 这个打印表只负责 BIP39 单词与序号的对应关系。
- 如果你还使用了 BIP39 passphrase（第 25 个词/密码短语），它不在这张表里，必须另外安全保存。
- 真正存钱前，最好先用一组测试助记词完整演练一次：打孔、还原、导入、验证都成功后，再处理正式资产。

## 六、最终验收演练

这一步建议在正式存钱前一定做一遍。

### 第一轮：测试助记词演练

先不要直接上正式资产，先拿一组测试助记词完整走流程：

1. 准备一组测试助记词。
2. 按本说明把它完整打到钛板上。
3. 把原始纸面助记词收起来，不再看。
4. 只看钛板，完整反推出整组助记词。
5. 把反推结果和原始测试助记词逐词逐位置比对。
6. 完全一致后，再进入下一轮。

只要这一轮有任何不一致，先停下，不要处理正式资产。

### 第二轮：正式版本盲恢复核对

正式助记词打完后，再做一次盲恢复：

1. 把原始正式助记词遮住或收走。
2. 只看钛板，独立反推整组助记词。
3. 逐词逐位置和原始正式助记词核对。
4. 如果你还用了 BIP39 passphrase，也要一起核对。
5. 全部一致后，才算钛板记录合格。

注意：

- passphrase 不在这张表里，必须单独保存并单独核对。
- 没有 passphrase 的钱包，和有 passphrase 的钱包，恢复出来会是不同的钱包。

### 第三轮：钱包恢复结果核对

如果条件允许，最好再做一次钱包级验证：

1. 用钛板反推出的助记词恢复到一个干净设备或临时环境。
2. 如果原钱包使用了 passphrase，要输入完全相同的 passphrase。
3. 恢复后，核对钱包是否和预期一致。
4. 最稳的是看恢复出来的首个收款地址、账户指纹或你事先记录的校验信息是否一致。

如果恢复出来的钱包标识不一致，就不要入金，先查错。

### 第四轮：小额实测

在正式放大额资产前，建议先做一次小额真实演练：

1. 先转入一笔自己能接受的小额资金。
2. 再用“只靠钛板 + 必要的 passphrase”重新恢复一次。
3. 确认能正确看到并控制这笔小额资金。
4. 小额演练成功后，再考虑放正式资产。

这样做虽然麻烦，但能最大限度降低“以为没问题，其实恢复不了”的风险。
