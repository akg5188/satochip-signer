# 只读离线副本制作建议

这份说明是给“长期保存”和“尽量防止误改、被改、丢失”用的。

目标不是做绝对不可篡改系统，而是把实际可操作的风险尽量压低。

## 一、建议准备几份副本

最实用的组合是：

- `1` 份工作副本
  - 放在你当前可信设备上，平时查看和打印用
- `1` 份只读离线副本
  - 平时不插电脑，不日常打开，只在核对或恢复时使用
- `1` 份异地副本
  - 放在不同地点，防火灾、水灾、盗窃和单点遗失

如果条件有限，至少也要做到：

- `1` 份本地副本
- `1` 份离线副本

## 二、推荐介质

按实用性排序，优先考虑：

### 1. U 盘离线副本

优点：

- 最容易做
- 拷贝方便
- 便于和纸质说明一起存放

缺点：

- 默认不是只读
- 插回联网电脑时仍可能被误删或误改

适合：

- 作为第一份离线副本

### 2. 只读控制更强的介质

可考虑：

- 带硬件写保护功能的存储介质
- 只在可信设备上短暂接入的外置 SSD
- 写一次后长期封存的光盘副本

适合：

- 作为“尽量少改、尽量少碰”的第二份副本

### 3. SD 卡说明

如果你使用全尺寸 `SD` 卡的写保护拨片，要注意：

- 它不是密码学防篡改
- 它也不是所有读卡器都会严格执行的绝对硬件防写

所以：

- 它可以作为“减少误写”的辅助手段
- 不能把它当成唯一的安全保证

## 四、推荐制作流程

### 第一步：只在可信环境制作

制作离线副本时，尽量满足：

- 当前设备状态可信
- 文件刚做完校验
- 不在陌生机器、网吧、共享电脑上操作

先运行：

```bash
cd /home/ak/钛板工具包_精简归档版
python3 verify_titanium_backup_kit.py
python3 verify_bip39_wordlist.py bip39_english.txt
```

只有都通过，才复制。

### 第二步：复制整个精简归档版

最省事的做法：

- 复制整个目录 `钛板工具包_精简归档版`

或者：

- 复制整个压缩包 `钛板工具包_精简归档版.tar.gz`

目录版的优点：

- 打开就能看
- 不用先解压

压缩包的优点：

- 更适合整包搬运
- 不容易少复制某个文件

最稳的做法是两者二选一，不要手工挑着拷。

### 第三步：复制完成后立刻复核

副本拷贝完成后，在副本介质上再次运行：

```bash
python3 verify_titanium_backup_kit.py
python3 verify_bip39_wordlist.py bip39_english.txt
```

要点：

- 不是只校验源目录
- 而是要在副本目录里重新跑一遍

只有副本自己验证通过，才算副本合格。

### 第四步：做标签

建议给副本介质贴一个简短标签，至少写：

- `钛板工具包精简归档版`
- 制作日期
- 版本日期
- 是否已验证

例如：

- `钛板工具包精简归档版 / 2026-04-06 / Verified`

## 五、怎样尽量做到“只读”

### 1. 使用原则

最重要的不是某个神奇介质，而是纪律：

- 平时不接入联网电脑
- 不拿来日常看电影、装文件、混放资料
- 不和钱包软件、浏览器缓存、下载目录放在同一介质里
- 只在需要核对或恢复时短暂接入

### 2. 实操建议

如果是 U 盘或移动 SSD：

- 做完副本后立刻拔出
- 平时封存
- 接入时只做查看、校验、复制，不在里面随手改文件

如果是支持写保护的介质：

- 复制和验证完成后，切到防写状态再封存
- 但仍然不要把它当成绝对防篡改

### 3. 介质分工

建议分成：

- `A`：工作副本
- `B`：只读封存副本
- `C`：异地副本

不要把唯一的一份副本既当工作盘又当封存盘。

## 六、怎么放

建议：

- 纸质说明和钛板可以放一起
- 数字离线副本单独装袋或装盒
- 干燥、避光、远离热源和潮湿环境
- 不和清洁剂、电池液、酸碱物品放一起

如果和钛板同盒保存：

- 数字介质不要直接摩擦钛板
- 中间加袋子、纸套或分隔层

## 七、多久检查一次

建议最少：

- 每 `6-12` 个月检查一次介质是否还能读
- 每次检查时重新跑一次：

```bash
python3 verify_titanium_backup_kit.py
python3 verify_bip39_wordlist.py bip39_english.txt
```

如果发现任何一项异常：

- 不要继续依赖这份副本
- 立即用另一份可信副本重建

## 八、最容易踩坑的地方

- 只复制了几个 PDF，忘了校验脚本和词表
- 只在源目录校验，没有在副本目录校验
- 把副本介质拿来顺手装别的东西
- 以为 `SD` 锁扣等于绝对防写
- 只有一份离线副本，没有异地副本
- 长期不检查，等真要用时才发现介质坏了

## 九、最短建议

如果你只想要一句最实用的话：

- 保留一份工作目录
- 再做两份完整精简归档版副本
- 每份复制完都在副本目录内重新校验
- 一份本地封存，一份异地封存

这样已经比“只在电脑里放一份”稳很多了。
