# 钛板工具包总说明

这套目录是给 `5cm x 5cm` 正方形钛金属板做 BIP39 英文助记词备份用的。

默认记录方式是：

- 用定位贴纸定点
- 用冲子在钛板上打出清晰可读的凹点
- 用 `bip39_a4_binary_print.pdf` 查词和还原

本说明默认你做的是“可读凹点记录”，不是把钛板完全打透。对钛板来说，这样更稳、更不容易让板子变形、开裂、毛刺过大，也更适合长期保存。如果你以后一定要做贯穿孔，务必先在同材质废片上完整试做，确认不会变形、不会裂边、不会影响识读后再上正式板。

## 一、这个目录里最重要的文件

- `a4_5cm_grid_sheet.pdf`
  - `5cm` 钛板定位贴纸母版，打印时必须 `100%` 比例，不能“适合页面”
- `bip39_a4_binary_print.pdf`
  - BIP39 英文词表二进制对照表
- `bip39_打孔还原说明.md`

- `bip39_最终检查清单_a4.pdf`
  - 正式打孔、盲恢复、入金前检查表
- `钛板工具包_速查版_a4.pdf`
  - 以后隔很久拿出来时，直接照着做的 A4 速查页
- `bip39_english.txt`
  - 官方 BIP39 英文词表本地副本
- `verify_bip39_wordlist.py`
  - 验证 BIP39 官方词表真伪

3. `bip39_打孔还原说明.md`
4. `bip39_最终检查清单_a4.pdf`

## 二、当前固定规则

当前这套工具包固定用下面这套规则，不要自己临时改：

- 单词范围：`0-2047`
- 每个单词对应 `11` 位二进制
- 位序从左到右：`1 2 4 8 16 32 64 128 256 512 1024`
- 有凹点：这一位是 `1`
- 没凹点：这一位是 `0`

也就是说：

- 最左边第一个点代表 `1`
- 第二个点代表 `2`
- 第三个点代表 `4`
- 一直到最右边第十一个点代表 `1024`

## 三、5cm 钛板的推荐用法

`a4_5cm_grid_sheet.pdf` 里的每个大方格都是一个 `50mm x 50mm` 的板位模板，内部是 `11 x 13` 点阵。

推荐排法：

- `12` 词助记词：用一块板，按从上到下 `1-12` 行记录，`13` 行留空做备用
- `24` 词助记词：用两块板
  - 第一块：记录第 `1-12` 词
  - 第二块：记录第 `13-24` 词
  - 两块板的第 `13` 行都留空，不要混入正式助记词

为什么建议把第 `13` 行留空：

- 给排错、补记、板号备注留余地
- 降低以后时间久了把板号和正式词位看混的风险

推荐把板号记在板背面、独立纸卡或密封盒标签上，例如：

- `Plate A / Words 1-12`
- `Plate B / Words 13-24`

不要把板号规则临时记在脑子里。

## 四、材料与工具

### 1. 板材

你现在已经有钛板，就继续用现有板材，不需要为了“更标准”重买。

如果将来需要补买或重做，优先建议：

- 商业纯钛 `ASTM Grade 2`

原因：

- TIMET 的 `TIMETAL 50A`（对应 `ASTM Grade 2`）资料写的是“good ductility and formability”，适合手工成形和加工
- 同类资料里，商业纯钛的可成形性通常优于高强度的 `Ti-6Al-4V / Grade 5`

这个“以后补买优先 Grade 2”的建议，是根据厂商资料做出的工程推断。

### 2. 冲子

最稳的组合是两支：

- `Prick Punch / 点冲`
  - 用来做轻定位点
  - Starrett 的说明里写到，点冲尖角更尖，小于 `60°`，能做出更窄更深、定位更准的点
- `Center Punch / 中心冲`
  - 用来把最终的识读点打清楚
  - Starrett 的说明里写到，中心冲尖角是 `90°`

如果你想让每个点的深浅更一致，可以再加一个：

- `Automatic Center Punch / 自动中心冲`
  - 不用锤子，靠下压自动触发
  - 适合先打一轮浅定位点，深浅一致，比较不容易手滑

一个可参考的最终点尺寸，是 `1.5mm` 左右的中心冲头。Starrett 的 `117AA` 中心冲就是 `1/16"`，约 `1.5mm`，并且说明里提到它是硬化回火钢、尖端居中、适合精确定点。

### 3. 其他工具

- 小号圆头锤或钳工锤
  - 目标是“可控、重复、不过猛”
- 稳固的钢砧块、台虎钳平台或厚钢块底座
- 夹具或台虎钳
  - 目的是让板子和底座都不滑
- 钢尺或卡尺
  - 用来核对贴纸打印是否真的是 `50mm`
- 无纺布或无尘布
- 高纯度异丙醇
  - 用来去掉手汗、盐分、胶痕和灰尘
- 一次性丁腈手套或干净塑料手套
- 干燥剂
- 湿度指示卡
- 无酸无缓冲纸
- 聚乙烯或聚丙烯密封盒

## 五、开始前先做这三件事

### 1. 验证 BIP39 词表

如果以后重下词表，先跑：

```bash
python3 verify_bip39_wordlist.py /你的/english.txt
```

只有输出 `VERIFICATION OK` 才继续。

### 2. 验证本地整套工具包

在本目录里跑：

```bash
python3 verify_titanium_backup_kit.py
```

只有所有文件都通过校验，才继续。

如果你自己在可信环境中有意修改过文件，例如更新说明、重生成 PDF 或增加新脚本，再运行：

```bash
python3 refresh_titanium_manifest.py
```

然后再用：

```bash
python3 verify_titanium_backup_kit.py
```

确认新的整套清单已经闭合。

### 3. 打印贴纸时必须核对尺寸

打印 `a4_5cm_grid_sheet.pdf` 时：

- 选择 `100%`
- 关闭“适合页面”
- 打印后用尺量一个大方格边长必须是 `50mm`

只要不是精确 `50mm`，这张贴纸就不要上正式板。

## 六、正式制作流程

### 第一步：先做同材质废片试打

正式上板前，先拿同材质废片试一轮：

- 看冲子会不会打滑
- 看凹点够不够深
- 看板子会不会明显鼓包、弯曲或裂边
- 看贴纸会不会因为敲击而移位

如果废片都不稳定，正式板先不要动。

### 第二步：清洁和贴纸定位

1. 用异丙醇把板面擦干净
2. 戴手套，减少汗液和盐分污染
3. 把 `5cm` 贴纸裁下来
4. 对准板边贴正
5. 再确认一次大方格和板边没有歪斜

### 第三步：准备查词环境

桌面只保留这些东西：

- 原始助记词
- `bip39_a4_binary_print.pdf`
- 当前要打的板
- 当前要打的工具

不要把多个草稿、多个词表版本、多个试验板混在一起。

### 第四步：逐词打点

对每个单词，严格按同一顺序：

1. 在 `bip39_a4_binary_print.pdf` 找到这个单词
2. 同时核对“序号”和“单词”都完全正确
3. 确认这一行的 `11` 位点阵
4. 在钛板对应这一行上，先用点冲或自动中心冲打浅定位点
5. 再核对一遍本行没有看错、没有偏行
6. 用中心冲把需要为 `1` 的位置打成最终可读凹点
7. 这一行做完后，立刻按 `1 2 4 8 ... 1024` 重新求和
8. 回查表格，确认还原出来的序号和单词与原单词完全一致

### 第五步：打点手法

推荐手法：

- 冲子尽量垂直于板面
- 先轻定位，再做最终深点
- 每一击尽量独立、稳定，不要连续乱补
- 一行做完再换下一行，不要跨行乱跳

注意：

- Starrett 的安全说明提到要戴护目镜
- Starrett 也提到不要用过大的锤子，小直径冲子用轻而可控的敲击更稳
- 如果自动中心冲已经能打出足够清晰的凹点，可以先在废片上确认后再决定是否直接用它做最终点

### 第六步：打错怎么办

如果正式词位上打错了：

- 不要靠“这个点应该问题不大”自我安慰
- 不要指望靠肉眼模糊修补继续用

最稳的做法是：

- 这块正式板作废或转为测试板
- 重新做一块

因为多一个点或少一个点，都会变成另一个合法序号，钱恢复不回来时不会给你“差不多也算对”的机会。

## 七、怎么还原

1. 按词位顺序一行一行读
2. 从左到右看 `11` 个位置，对应：

`1 2 4 8 16 32 64 128 256 512 1024`

3. 哪个位置有凹点，就把那个数字加进去
4. 得到总和后，去 `bip39_a4_binary_print.pdf` 查对应序号
5. 抄下对应单词
6. 按原顺序还原出整组助记词

例子：

- 如果某行凹点在 `1 + 4 + 8`
- 序号就是 `13`
- 回表里查到 `13-accuse`
- 该词就是 `accuse`

## 八、最容易出错的地方

- 把位序看反
- 看到了单词但没核对序号
- 行号偏了一行
- 打错后继续往下做
- `12` 词和 `24` 词时板号记混
- 忘了单独保存 BIP39 passphrase

如果你用了 BIP39 passphrase：

- 它不在这张二进制板里
- 必须单独保存
- 恢复时必须一起输入

## 九、长期保存与防腐

钛在大气和很多环境下本来就很耐腐蚀，但“耐腐蚀”不等于“可以随便放”。长期保存真正要防的是：

- 湿气
- 粉尘
- 盐分
- 胶残留
- 氯化物污染
- 长时间密封后积累的腐蚀性挥发物

### 1. 打完后先清洁

打孔完成后：

1. 去掉贴纸
2. 清除胶痕、粉尘和敲击碎屑
3. 用异丙醇擦净
4. 完全干燥后再入盒

不要让汗液、胶痕、灰尘、盐分长期留在板上。

### 2. 包装材料

长期保存优先用：

- 无酸无缓冲纸
- 聚乙烯袋
- 聚乙烯或聚丙烯密封盒
- 食品级带密封圈盒
- 干燥剂
- 湿度指示卡

不建议长期直接接触这些材料：

- 劣质泡棉
- 易老化聚氨酯泡棉
- 含氯塑料
- 来源不明的橡胶
- 有强烈气味的胶、油、泡沫、涂层

CCI 的金属保存说明明确提到：

- 低湿度有利于减缓金属腐蚀
- 可使用干燥剂建立低湿微环境
- 稳定材料可选聚乙烯、食品级聚苯乙烯、无酸无缓冲纸
- 不建议使用容易释放有害物的材料

### 3. 湿度控制

这类重要小金属件，建议：

- 装入密封良好的小盒
- 盒内放干燥剂
- 盒内放一张湿度指示卡

CCI 的建议里提到：

- 稳定金属一般可放在 `35%-55% RH`
- 如果希望尽量压低腐蚀风险，可在封闭容器中用干燥剂建立更低湿环境
- 对金属件来说，干燥剂是建立低湿环境的最好办法之一

如果你要做“长期、少打开、重安全”的存放，建议目标是：

- 盒内尽量长期保持低湿
- 至少每年看一次湿度卡
- 干燥剂失效就及时再生或更换

“每年至少检查一次”是我根据保存资料给你的实用建议。

### 4. 放置位置

不要放在这些地方：

- 靠窗
- 空调出风口旁
- 热源旁
- 外墙冷面附近
- 潮湿地下室
- 漂白剂、酸、碱、清洁剂旁

CCI 的保存说明提到，金属最好远离窗、门、通风口和加热设备，也要避免冷表面附近的结露问题。

### 5. 处理和接触

拿板时建议：

- 戴干净塑料手套或丁腈手套
- 板和板之间用无酸纸隔开
- 不要让板子互相硬碰硬摩擦

CCI 的说明里提到，手汗和盐分会给金属带来问题，拿取时应戴合适手套。

### 6. 双份保存

如果你真要长期存正式资产，建议至少准备两套物理备份，并放在不同地点。

这不是为了“更高级”，而是为了防：

- 火灾
- 盗窃
- 水灾
- 单点遗失

## 十、防篡改与长期可验证

### 1. 词表防篡改

以后只信下面三类来源之一：

- 官方说明页
- 官方原始词表
- 官方固定提交版本词表

先验证，再使用。

### 2. 本地工具包防篡改

以后每次重新使用前，先在本目录运行：

```bash
python3 verify_titanium_backup_kit.py
```

如果有任何文件校验失败：

- 先停下
- 不要继续打孔
- 不要继续还原
- 不要继续入金

### 3. 离线留档

建议长期保留这三份：

- 一份纸质打印版
  - `钛板工具包_速查版_a4.pdf`
- 一份本地目录副本
- 一份额外离线副本
  - 例如只读 U 盘、写保护存储卡、另一台离线设备

最稳的是：

- 纸质说明负责“人能看懂”
- 本地文件负责“能重新验证”
- 额外离线副本负责“本机坏了或被改了还有第二份”
- 如果你在可信环境中主动更新过目录文件，记得重新运行 `refresh_titanium_manifest.py`

关于离线副本具体怎么做、用什么介质、怎么复制和怎么复核，见：

- `只读离线副本制作建议.md`

## 十一、正式放钱前必须做的演练

1. 先拿测试助记词完整打一次
2. 遮住原词，只靠钛板盲恢复一次
3. 用恢复结果导入到干净环境
4. 核对恢复的钱包标识是否一致
5. 先做一笔小额真实测试
6. 只有小额实测成功，才考虑放正式资产
